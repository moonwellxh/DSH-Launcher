# 代码类命名空间（code.md）

> 适用：程序/脚本/接口/算法/批处理等代码型产出物。本文件在 L1 快筛后、L2 前读取。对应导引单条款：通用 [G-001..G-008]＋代码类 [C-001、C-002]。

## 高频缺陷清单（审查时优先排查）
- [CD-01]（边界）公开接口未处理非法输入：空值/越界/类型不符/编码异常。
- [CD-02]（边界）数值边界错误：`<` vs `<=`、`0`/`-1`/哨兵值、整数溢出。
- [CD-03]（一致性）调用处与接口签名不一致；返回值语义歧义（None/空串/异常混用）。
- [CD-04]（一致性）硬编码魔法值散落，同一常量多处定义且不统一。
- [CD-05]（逻辑）并发/竞态：读写竞争、非原子检查-动作序列、死锁窗口。
- [CD-06]（完整性）异常路径缺失：资源未释放、部分失败无补偿/回滚。
- [CD-07]（完整性）既有测试未覆盖变更分支；测试自身断言无效。
- [CD-08]（事实性）注释/文档与实现不符；算法复杂度声明与实际不符。

## 聚焦区默认先验（热力图 prior，无 metrics 历史时用）
| 聚焦区 | 默认 prior | 说明 |
|---|---|---|

## 对抗视角提示
有 L0 脚本/静态工具（编译、lint、既有测试）先跑，脚本输出即证据，禁止模型重算；修复回归验证必须跑既有测试集（对应 [C-002]）；并发问题按"最小复现推理链"要求证据，防无证据恐慌式意见。
