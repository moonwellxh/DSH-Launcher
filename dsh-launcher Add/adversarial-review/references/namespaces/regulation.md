# 规范类命名空间（regulation.md）

> 适用：引用规范/标准的条文解读、符合性判定、测量基准、提资类产出物。本文件在 L1 快筛后、L2 前读取。对应导引单条款：通用 [G-001..G-008]＋规范类 [R-001、R-002]。此类对象"外部硬约束"即规范本体，合规性缺陷直接决定可用性。

## 高频缺陷清单（审查时优先排查）
- [RG-01]（合规性）引用标准非现行有效版本（已废止/已替代/未生效）。
- [RG-02]（合规性）条款号错误或条款归属标准张冠李戴。
- [RG-03]（合规性）强制性条文（GB 中的"必须/应"）理解偏差或遗漏。
- [RG-04]（一致性）测量基准类表述（起算点、可踏面、净高起算等）与现行条文说明不一致。
- [RG-05]（一致性）正文结论与所引条文的适用范围（适用对象/地域/前提）不符。
- [RG-06]（边界）界限值（限值"不大于/不小于/宜/可"）语义混淆，边界含否不清。
- [RG-07]（完整性）多本规范交叉时的冲突未协调（新老规范、通用/专项）。
- [RG-08]（完整性）引用位置只有标准号没有具体条款，无法复核。

## 聚焦区默认先验（热力图 prior，无 metrics 历史时用）

## 对抗视角提示
"标准现行有效性与条款号"必须逐条给出官方检索出处（标准号＋条款号），查不到即 evidence 不足；impact 赋值：强制性条文/安全相关＝3、对外承诺数据＝2、一般＝1。测量基准类结论需对照条文说明原文复核。
