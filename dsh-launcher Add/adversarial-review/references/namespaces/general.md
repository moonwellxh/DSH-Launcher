# 通用层命名空间（general.md）

> 适用：审查对象类型不明、或无专业归属的一般产出物（方案/汇报/说明/清单等）。**不明按本层处理并告知用户**。本文件在 L1 快筛后、L2 前读取，用于优先排查高频缺陷与确定聚焦区先验。

## 高频缺陷清单（审查时优先排查）
- [GN-01]（事实性）无来源数据：关键数字/结论未标注出处。
- [GN-02]（一致性）交叉引用失效：章节号、图表号、编号指向不存在的目标。
- [GN-03]（一致性）前后口径不一：同一术语/数字在文内多处不一致。
- [GN-04]（完整性）边界缺失：空值、极值、例外情形、临界尺寸未处理。
- [GN-05]（合规性）引用外部硬约束（规范/合同/需求）却未核对符合性。
- [GN-06]（表述）模糊兜底措辞："原则上/一般情况下/等"充当依据。
- [GN-07]（逻辑）因果断裂：结论与论据之间缺推理链或隐含假设未声明。
- [GN-08]（完整性）结构编号不连续、层级错乱、图表缺题号。

## 聚焦区默认先验（热力图 prior，无 metrics 历史时用）
| 聚焦区 | 默认 prior | 说明 |
|---|---|---|
| 交叉引用一致性 | 0.35 | 通用层最高发缺陷密度 |
| 边界条件 | 0.25 | 例举/极值/例外 |
| 数据与逻辑 | 0.25 | 无来源数据、因果断裂 |
| 外部硬约束符合性 | 0.15 | 依对象而定，涉规范/合同时上调 |

## 对抗视角提示
对象涉规范/合同/需求时，把"外部硬约束符合性"视为 impact=3 的强制区；只提供事实性陈述不提供来源者视为 high 置信疑点，提交用户裁决。
