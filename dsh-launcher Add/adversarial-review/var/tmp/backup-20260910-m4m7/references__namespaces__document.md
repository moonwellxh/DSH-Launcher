# 文档类命名空间（document.md）

> 适用：对外文档/报告/说明/方案书/规范解读等以文字图表为主的产出物。本文件在 L1 快筛后、L2 前读取。对应导引单条款：通用 [G-001..G-008]＋文档类 [D-001、D-002]。

## 高频缺陷清单（审查时优先排查）
- [DC-01]（一致性）图表数据与正文表述不一致；表格合计错误。
- [DC-02]（一致性）章节/图表/条款编号不连续或交叉引用指向错误章节。
- [DC-03]（事实性）引用的外部资料版本过期、条号张冠李戴。
- [DC-04]（完整性）关键术语首现未定义；缩略语表缺失。
- [DC-05]（完整性）边界/例外/假设条件在方案性文档中未声明。
- [DC-06]（合规性）对外承诺数据（性能/指标/时限）无测算或实测支撑。
- [DC-07]（逻辑）结论先行但论据顺序错乱、缺论证链。
- [DC-08]（表述）单位、量纲、边界（含/不含）交代不清。

## 聚焦区默认先验（热力图 prior，无 metrics 历史时用）
| 聚焦区 | 默认 prior | 说明 |
|---|---|---|
| 交叉引用一致性 | 0.35 | 长文档编号体系最易错 |
| 数据与事实 | 0.30 | 图表数据、来源与量纲 |
| 外部硬约束符合性 | 0.20 | 涉规范/合同/需求时上调至 0.4 |
| 边界条件 | 0.15 | 方案假设与适用边界 |

## 对抗视角提示
对外交付物把"对外承诺数据"一律按 impact=2~3 复核（有来源→核对口径；无来源→阻断候选）；编号体系建议用 L0 风格确定性检查先行（连续性与引用存在性）。
