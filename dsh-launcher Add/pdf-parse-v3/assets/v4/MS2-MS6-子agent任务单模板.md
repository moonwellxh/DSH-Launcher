## 一、每批子 agent 标准自含 spec 字段（四件套，缺一不可）
每个子 agent 任务单必须包含以下**自含**信息（不依赖本会话上下文，子 agent 只经接口/磁盘产物协作）：

| 字段 | 内容 | 来源 |
|---|---|---|
| 模块职责 | 该模块做什么、边界（对照设计书 §6.x 每模块「职责/输入→输出/数据结构/异常与降级」） | 设计书 §6.x |
| 输入输出契约 | 签名级接口（函数签名 + 返回结构 + 异常）。**不得跨模块共享上下文推理** | 设计书 §3.1（M4/M6/M7/M8 契约）、§7 局部代码 |
| 需求编号 | 该模块对应的 FR/R/V/KD/MS 编号（逐条） | 需求书 v2.3 + 粗架构 v0.6 + 设计书 §12 |
| 编码纪律 | Python 单进程；PowerShell 薄壳；含中文脚本 UTF-8 BOM；数据文件 UTF-8 无 BOM；密钥只读用户级目录；幂等不覆盖原文；CALIB 初值标注；不伪造坐标精度 | 任务书「三、工程纪律」+ 设计书 §4.2 注 |
| 自证要求 | 交付附 G-008（关键决策+依据条款号；G-001/002/003/005/006/007 已自检；诚实声明列契约级未实现清单与实测 vs 初值） | 任务书「四、自证声明」（G-008） |

**协作纪律**：子 agent 之间**只经接口与磁盘产物协作**，不共享上下文推理；产物写约定位置（`assets/v4/` 模块文件 + `work/{triage,render,pages,glm,ocr,tables,gate,ladder,figures,cache,ledger}/`），进度读磁盘产物（FR-G1），幂等跳过已完成项。
