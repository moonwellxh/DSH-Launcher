## 已自检项

- **G-001（数字有来源）**：usage/cost 均由实测 usage 换算；`page_0001` fixture 的 prompt=694/completion=84 取自黄金夹具原始响应；cost=0.000156=实测换算，非初值。
- **G-002（交叉引用真实）**：字段名与详细技术设计 §2.4/§4.3/§5.3 一致（defect_class、verified_by、GateResult->failures/unavailable_signals/low_signal/hints 等不在本阶段，未触碰）；模块编号 M4/M12、决策 KD6、里程碑 MS-1 均对应真实编号。
- **G-003（数值带单位/口径）**：cost 单位为 CNY（`cost_cny`），usage 为 tokens，价格为 ¥/百万 tokens，符合设计口径。
- **G-005（边界显式）**：退化 bbox（crop_degenerate）在 M2/M14 处理（本阶段不涉）；`output_length_exceeded` 显式不重试并带 degrade_hint；`budget_limit=0` 显式拦截；egress 短路显式抛错并落标记。
- **G-006（无模糊兜底）**：无「原则上/一般情况下」类措辞；故障一律落到具体 kind + degrade_hint。
- **G-007（编号/术语统一）**：`VisionError.kind` 枚举闭集；`task_type` 用常量 TASK_FULL_PAGE/TASK_CROP/TASK_NARROW；`channel` 用 GLM_CHANNEL/SECOND_OPINION_CHANNEL；与设计书术语一致。

## 诚实声明（本阶段粒度边界）

1. **契约级未实现清单**（属后续里程碑，本阶段只给接口与最小实现）：M2 渲染与 registry 登记（`build_render_reg` 为 MS-1 convenience 推导，M2 接入后禁用）、M6 适配层、M7 校验门、M8 缺陷阶梯、M9 structurer、M10 figures、M11 quality、M13 serialize、M14 geo_rebuild；`_narrow_task_prompt` 为骨架模板（真正窄任务 prompt 在 MS-3 以试点册台账封闭化后定型，版本号 `prompt_version.narrow_task=nt-1.0` 治理）。
