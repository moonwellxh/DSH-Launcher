## 2. 缺陷类正式定义 D1/D2/D3（落实 m-3）

本节为 D1/D2/D3 的**正式定义地**（台账 `defect_class`、FR-E9、MS-3 验收的判定基准）；架构思考 §1 为实测出处，本节定义与之逐条对应并补全判定形式化。缺陷类枚举闭集为 `{D1, D2, D3}`；占位空 td 怪癖由适配层处理（架构思考 §1-D4；本设计 §7.1.1 的「占位丢弃」分支在 while 预跳实现下为意图记录、不可达，实际由守恒门兜底——本设计 R3-A 轻微-2，实现期实装或删除），不构成缺陷类；跨页续表属正常形态处理（架构思考 §1-D5），不构成缺陷类。

### 2.1 D1 合并格拼接（标签列纵向合并格内多值无分隔拼接）

- **定义**：表格中 rowspan>1 的合并格（典型为等级/标签类列，如耐火等级、最多允许层数），其格内承载的多个逻辑值（每个被覆盖行一个值）**无分隔直接拼接**为一个字符串，导致行↔值对应关系丢失。
- **实测实例**：「一级二级」（两行值一级/二级拼接）、「不限31」（三行值不限/3/1 拼接），page_0013（架构思考 §1-D1；对拍报告 §4）。
- **发生率**：7/73 表 ≈ 9.6%（对拍报告 §8.3，180 页整册补测）。
- **检测签名（确定性正则）**：`rowspan>1 或 colspan>1 的合并格` 且格内文本（去空白后）命中 `[一-鿿][0-9] | [0-9][一-鿿] | 级[一二三]`（analyze_batch.py 第 28 行 DEFECT_RE 原型，本设计 §7.2.2 沿用并参数化入 config）。已知误报：原文即汉字+数字连排（对拍报告 §8.3 定级为误报页 0031/0085/0113 等；「12 命中约 3–5 误报」出自架构思考 §1-D1），误报不静默丢弃——入缺陷阶梯由规则拆分自检或裁剪复核证伪（架构思考 §1-D1 处理阶梯）。
- **修复路径**：规则拆分（封闭枚举集 + 行数对齐校验）→ 裁剪重译 → 第二意见 → 标记（本设计 §7.3）。

### 2.2 D2 rowspan 过声明（幻影列 / 幻影行）

- **定义**：单元格声明的 rowspan 超出结构上界，分两种：**列向过声明**（表头格 rowspan > 表头实际 tr 数；单行表头被声明 rs=2，首行数据被推入多余「幻影列」）与**行向过声明**（任一格 rowspan > 其锚行之后的剩余 tr 数，造出「幻影行」）。两者都使展开网格出现集中空洞、守恒失败。
- **判定形式化**：列向过声明量 D = 表头最大声明 rowspan − 表头 tr 数（D>0 即列向 D2）；行向过声明 = 存在格 (r, rs) 使 rs > max_tr − r（max_tr = 全表 tr 数）。本设计 §7.1.2 `overdeclare_info()` 同时计算两者。
- **实测实例**：page_0087——`<thead>` 单 `<tr>` 内 5 个 `<th rowspan="2">`（列向过声明 D=1，首行数据被推入第 6–10 列）；且 `序号 7` 格 `rowspan="11"` 仅覆盖锚行 + 9 子行 = 10 行（行向过声明 1，造出幻影行）。归一化后应还原 12×5 守恒网格（本设计 §7.1.3 算术核验；MS-2 以黄金夹具重放复核，对拍报告 §8.2 归因 1 的落点）。
- **发生率**：含在 10/73 表守恒失败中（对拍报告 §8.2）。
- **检测签名**：守恒检查失败（空洞）+ 过声明判定（列向 D>0 或行向 rs>avail）。
- **修复路径**：过声明归一化（本设计 §7.1.3，rs 收缩到结构上界后重展开，结果必过守恒门）→ 裁剪重译 → 第二意见 → 标记。

### 2.3 D3 无横线子行错位

- **定义**：序号列（或等价分组列）合并格 rowspan=k 覆盖 k 个无横线分隔的子行，各子行自带数值；GLM 将某子行的数值对到相邻子行（错位）。**错位后网格仍守恒**，故守恒门不可见——这是 D3 被定为「最危险缺陷类」（架构思考 §1-D3）的原因。
- **实测实例**：page_0087 中序号 6 的分项(6)的 0.45/非燃烧体 被划给序号 7 的首行（架构思考 §1-D3）。
- **检测信号**（双观测，算法层独立、共享本地 OCR 行 box 上游为已知共因残余——粗架构 KD9、报告2-R1 勘正口径；**第三轮方向裁决后均为提示信号 hint，不构成放行否决，需求书 FR-E8 v2.3 同步**）：
  1. 交叉对位（KD4）：本地 OCR 行级文本数值与网格行数值按行对位，不一致即产出 D3 hint（本设计 §7.2.3）；
  2. 几何错位检测（KD9）：序号格 rs=k 的 y 覆盖带内 OCR 行 box 聚类行数 ≠ k，或数值词 x 聚类落带异常，产出 D3 hint（本设计 §7.2.4）。
  （**D3 终裁**在第二意见窄任务逐行转写，传感器级独立，本设计 §8.4。）
- **降级口径**（需求书 FR-E8）：hint/低信号区表不经确定性信号直接放行，须触发第二意见转写复核；仅单一信号可疑且无法复核时不得自信放行，按 FR-E5 标记 uncertain；双信号同蒙（OCR 行分段失效）时按本设计 §8.4 规则处理。
- **修复路径**：无规则修复（D3 无确定性修复手段）→（hint/低信号触发）第二意见窄任务逐行转写（传感器级独立通道，报告2-R1 建议 2 已并入需求书 FR-D4/KD9；**不经裁剪重译**，因 GLM 裁剪重译会复现同错位，本设计 §7.3.1）→ 标记。

## 3. 坐标系与渲染登记（FR-B2 详细设计）

### 3.1 单一坐标系（承粗架构 KD2，不可变更）

全系统唯一坐标基准 = **渲染页像素系**（原点左上，x 右 y 下，单位 px）。GLM 块 bbox_2d 的 data_info 页宽高 = 渲染页宽高（对拍报告 §5 实测一致，page_0087 实测 `data_info.pages=[{height:2714,width:1860}]` 与渲染 PNG 一致）；本地 OCR 行 box 同源同系；文字层路径的 PDF 点系坐标在入库前经登记参数换算为像素系。PDF 物理点（pt）仅作登记字段保留，供复算与重新裁剪。

### 3.2 变换登记数据结构（每页一条，落盘 `work/render/registry.jsonl`）

```jsonc
{"page": 87,
 "pdf_rect_pt": [595.0, 842.0],     // PyMuPDF page.rect（宽,高）
 "target_width": 1860,              // 渲染目标宽 px（指定值，优先于 dpi）
 "dpi": 225,                        // 派生值 = target_width/pdf_rect_pt[0]×72 ≈ 225.1（本设计 m-05 修正）
 "pixel": [1860, 2714],             // 实际渲染像素（宽,高）
 "scale": [3.1261, 3.2233],         // pixel/pdf_rect_pt，逐轴（1860/595=3.1261, 2714/842=3.2233）
 "render_sha1": "…",                // 页图内容哈希（缓存指纹要素，本设计 §4.3）
 "downsampled_from": null}          // >10MB 降采样重渲染时记原档位（需求书 §8 边界）
```

登记纪律（本设计 m-05）：`dpi` 与 `target_width` 二选一为**指定值**、另一为**派生值**，写入登记时二者必须满足 `dpi = round(pixel[0]/pdf_rect_pt[0]×72)`，禁止自相矛盾（原示例 dpi=220 与 pixel=1860 互斥，已按 page_0087 实际 225.1 修正）。

### 3.3 换算与裁剪代码（M2 render.py 内建，FR-B2 验收「给定 bbox 可程序复算裁剪区」）

```python
def px_to_pt(box, reg):            # box=[x1,y1,x2,y2] 像素系 → PDF 点系
    sx, sy = reg["scale"]
    return [box[0]/sx, box[1]/sy, box[2]/sx, box[3]/sy]

def pt_to_px(box, reg):            # PDF 点系 → 像素系（文字层路径入库前换算）
    sx, sy = reg["scale"]
    return [round(box[0]*sx), round(box[1]*sy), round(box[2]*sx), round(box[3]*sy)]

def crop_png(png_path, box_px, out_path, pad=8):
    """按像素 bbox 裁剪页图（pad 为安全边际 px）。GLM 裁剪重译、图片文件化、
    FR-A4 区域追加解析共用此入口；坐标越界即抛 RenderError（见本设计 §10）。"""
    from PIL import Image
    im = Image.open(png_path)
    x1, y1, x2, y2 = box_px
    x1 = max(0, x1-pad); y1 = max(0, y1-pad)
    x2 = min(im.width, x2+pad); y2 = min(im.height, y2+pad)
    if x2 <= x1 or y2 <= y1:
        raise RenderError(f"crop_degenerate: {box_px} on {png_path}")
    im.crop((x1, y1, x2, y2)).save(out_path)
    return {"bbox_px": [x1, y1, x2, y2], "pad": pad}
```

**复算自检**（单元测试）：对黄金夹具随机 10 个块 bbox，`pt_to_px(px_to_pt(b))` 与 b 的逐轴差 ≤1px（取整误差），超差即 RenderError 并入报告（R7 缓解的落地）。

**pad 分工（本设计 C-3）**：`crop_png` 默认 `pad=8` px 供裁剪重译/FR-A4 区域解析；图片文件化（M10）用 `config.figures.crop_pad_px=5`（研究报告 §5 实验口径）——两者用途不同、各自独立，不冲突。

### 3.4 渲染参数与 10MB 边界

GLM 单图输入上限 10MB（需求书 §10 技术选型表；报告1-m4 要求闭环）。render.py 流程：按档位渲染 → PNG 字节 >10MB → 按降采样档序列（本设计 §4.2 `resolution_steps`，初值 [220, 180, 150] dpi，来源：本设计给定初值，MS-4 以试点册最大页图标定）逐级重渲染 → 仍超限则该页 GLM 路径诚实标记 `status=unreadable, reason=render_oversize`，本地管线（ocr_channel + geo_rebuild）继续。每次降采样在登记中更新 `dpi/pixel/scale/downsampled_from`，保证坐标链始终与实际上传图一致。

### 4.3 缓存指纹（KD6 扩展定稿，落实 m-2；MS-1 缓存验收依据）

粗架构 KD6 原要素 = sha1(pdf 文件 + 页码 + 渲染参数 + 型号)。**定稿要素**（防跨区域/跨任务错误命中）：

```python
import hashlib, json

def cache_fingerprint(*, doc_sha1: str, page: int, task_type: str,
                      bbox, render_reg: dict, model: str,
                      prompt_ver: str, retry: dict) -> str:
    """KD6 定稿。task_type ∈ {full_page, crop_retranslate, narrow_task}；
    bbox: 整页为 None，裁剪重译/窄任务为像素系 [x1,y1,x2,y2]（已含 pad）；
    retry: {"seq": 0, "feedback_sha1": null} —— FR-D8 定向重试携带失败原因
    反馈时 seq=1 且 feedback_sha1 为反馈文本哈希，保证重试不命中首次缓存。"""
    payload = {
        "doc": doc_sha1,                       # PDF 文件内容 sha1
        "page": page,
        "task": task_type,                     # 任务类型（跨区域隔离维度之一）
        "bbox": bbox,                          # 裁剪 bbox（None=整页）
        "render": {"dpi": render_reg["dpi"],
                   "pixel": render_reg["pixel"],
                   "img": render_reg["render_sha1"]},   # 页图内容哈希
        "model": model,                        # 型号+端点（端点变更即换型号串）
        "prompt": prompt_ver,                  # prompt 模板版本
        "retry": retry,                        # 重试维度
    }
    canon = json.dumps(payload, sort_keys=True, ensure_ascii=False, separators=(",", ":"))
    return hashlib.sha1(canon.encode("utf-8")).hexdigest()
```

缓存布局与纪律：

1. 路径 `work/cache/<channel>/<task_type>/<fingerprint>.json`，channel ∈ {glm, deepseek, qwen}；条目 = 完整原始响应 + 台账行（usage/cache_hit=false 首跑）。命中即零计费返回（台账记 `cache_hit=true, usage=null`）。
2. **隔离不变式**（单元测试断言）：同页不同 bbox 指纹不同；同 bbox 不同 task_type 指纹不同；同任务 retry.seq 0/1 指纹不同；渲染档位变更（降采样）指纹不同。
3. 指纹要素中 `render.render_sha1` 使「同 PDF 重渲染参数不变」命中、「PDF 内容变更」必然失效；不以文件路径/mtime 为要素（路径迁移不炸缓存，内容变更不错误命中）。
4. 中间产物（网格表、校验结果）不入缓存——其由确定性代码从缓存的原始响应再生（粗架构 KD6 备选否决理由沿用）。

### 5.4 单元格 bbox 裁决（粗架构 §11 遗留项）

**裁决：默认 `bbox=null`，可选比例估算。** 理由：① GLM 交付块级 bbox、未交付单元格级坐标——对拍报告 §8-L2 为「已确认块级；单元格级坐标**待细查**」，架构思考 §3 盲区行实测确认「单元格级坐标」缺失，本设计据此按未交付处理；单元格 bbox 只能是估算值，写入 JSON 会伪造溯源精度（违反需求书 §2.1-4「可溯源」的诚实含义）；② FR-B1 的溯源要求在表级已由表块 bbox + lines[] 满足；③ 需要格级定位的下游（如裁剪复核）可按「表块 bbox × (row/n_rows, col/n_cols) 均分带」程序复算——该算法写进交付说明，比存一个不可声明精度的数更诚实。配置 `adapter.cell_bbox_estimate=true` 时才写入估算值并附带 `"bbox_estimated": true` 标记。

## 6. 模块详细设计（M1–M14）

> 每模块：职责 / 输入→输出 / 数据结构 / 异常与降级 / 关键算法。处置（复用/改造/提炼/新建）与资产来源承粗架构 §2/§5，此处不重复。异常码全集汇总见本设计 §10。

### 6.1 M1 triage.py（改造 pdf_text_probe.py）

- **职责**：分诊（text/scanned/hybrid）+ 版式质量探测（栏/倾斜/DPI）+ 退化输入探测 + 页内区域级探测（FR-A4）+ 伪文本层重路由触发（FR-A2）。
- **输入→输出**：PDF → `work/triage.json`：`{page_count, encrypted, locked, degraded: {zero_page, blank_pages[]}, pages: [{page, verdict, ratio, printable, layout_hint, skew_deg, dpi_ok, intra_regions: [...]}]}`。
- **关键算法**：可读率判定沿用 pdf_text_probe.py 阈值（TEXT_MIN_RATIO=0.50 / PSEUDO_MIN_RATIO=0.30，技能经验沉淀）；倾斜探测用文本行 bbox 主方向角（>1.5° 记 deskew 需求，初值 1.5°，CALIB: MS-4；R4 前置）；FR-A4 页内探测见本设计 §7.4。
- **异常与降级**：encrypted/locked → `TriageError(encrypted)` 优雅报错（pypdf FileNotDecryptedError 既有处置沿用）；零页/全空白 → `degraded` 标记 + 整体退出码 3（不崩溃，FR-A1）；探测失败的单页 verdict=unknown → 按 scanned 路由（保守，多花钱不丢信息）。

### 6.2 M2 render.py（改造包装 render-pages.ps1）

- **职责**：页渲染 + 变换登记（本设计 §3 全部内容）+ 10MB 降采样（本设计 §3.4）+ **FR-A4 命中文字层页的按需渲染与登记**（本设计 L-8：§7.4 检出区域需 GLM 裁剪/几何重建时，先渲染该页并写 registry，本设计 §6.2/§7.4 触发链闭合）。
- **输入→输出**：PDF+页码清单（含 FR-A4 按需追加）→ `work/pages/page_NNNN.png` + `work/render/registry.jsonl`。
- **异常与降级**：渲染失败页记 `RenderError(page)` 并跳过该页视觉路径（走本地 OCR 兜底 + 标记）；`crop_degenerate` **上浮至编排层**（不进缺陷阶梯，R7；与本设计 §10 行口径一致，L-7）。
- 编排内直接以 PyMuPDF `page.get_pixmap()` 渲染（KD7 Python 单进程）。**处置偏离声明（本设计 m-08/L-2 修正）**：粗架构 §5 对 render-pages.ps1 记「改造（包装）」，本设计实为「提炼进 Python、ps1 不再承担数据流」——偏离依据为 KD7（粗架构 §6/§11 所载 ps1/py 混合编码缺陷记录），本条为对粗架构 §5 处置的显式修订。

### 6.3 M3 textlayer.py（复用 pdf_layout.py）

- **职责**：文字层提取——词/行 bbox、字号、阅读序、页眉页脚剔除、表格确定性提取（pdfplumber find_tables，FR-C3）。
- **输入→输出**：PDF → 页 JSON（lines[] 含 `source=layout`、size/font；tables 映射为网格模型）。
- **关键算法**：pdf_layout.py 的 `_collect/_detect_columns/_order_lines/页眉页脚重复剔除` 原样复用（152 行，技能资产）；坐标由 pt 经 pt_to_px 换算入库（本设计 §3.3）；pdfplumber 表 → 网格：以其 cells 坐标聚类出行列带后归格，产出同样过校验门（FR-C3 验收「无错列」）。**FR-E3 页原文交叉（文字层路径，本设计 m-14）**：表内数值 token 必须为页 lines[] 文本数值 token 集合的子集（防幻觉数值，确定性 0-token）。
- **异常与降级**：可读率过低（伪文本层）→ 返回 `reroute_signal` 触发 M12 重路由（FR-A2）；pdfplumber 表提取异常 → 该表放弃确定性路径、标 `locatable=false`、交 FR-A4/几何重建兜底，不阻塞页文本。

### 6.4 M4 vision_client.py（提炼 shootout.py GLM/Qwen 两客户端基座 + **新建 DeepSeek 客户端** + batch_glm.py 断点）

- **职责**：**唯一出域点**。GLM 整页解析（`glm_parse_page`）、GLM 裁剪重译（`glm_reparse_crop`）、第二意见窄任务（`second_opinion_task`，vendor=deepseek/qwen）；重试/限流/超时；usage 台账；指纹缓存（本设计 §4.3）。
- **资产声明勘正（本设计 MAJ-2 修复）**：shootout.py 实有 GLM（call_glm）与 Qwen（call_qwen）两客户端、load_keys 仅支持 zhipu/dashscope（经全文核对），**无 DeepSeek 客户端代码**——「三厂商基座」承自粗架构 §5 但不实，DeepSeek 通道为**新建**（OpenAI 兼容 chat/completions，复用 Qwen 的请求骨架改造），本设计不沿袭该不实表述。
- **契约**：在粗架构 §3.1 签名基础上**增** `glm_reparse_crop(..., retry={seq, feedback_sha1})` 参数（KD6 指纹重试维度的载体，本设计 §4.3）；补全异常面：`VisionError(kind=network|http_4xx|http_5xx|timeout|schema_invalid|output_length_exceeded|budget_exceeded|no_key|egress_blocked)`。
- **关键算法**：
  - 重试：网络/5xx/timeout 指数退避 ≤3 次（0.5s/2s/8s，温和限流沿用 batch_glm.py `sleep(0.3)` 纪律）；4xx 不重试；`finish_reason==length` 或空 content 且已计费 → 不重试，抛 `output_length_exceeded` 供 M8 爆破定位（FR-D6）。
  - strict schema 校验：second_opinion_task 响应先过 JSON Schema（status/data/rowspan/colspan/header_rows/confidence/issues 全字段，FR-D4），不合即 `schema_invalid` 判失败，不进入对位。
  - 限流：单进程串行（KD7），GLM 整册实测串行 4.25s/页均值够用（对拍报告 §8.1）。

#### 7.1.1 展开（含占位空 td 丢弃；提炼自 evaluate.py 第 33–83 行，逻辑等价、接口升级）

```python
import re
from bs4 import BeautifulSoup

def expand_table(table_tag):
    """HTML <table> → 展开网格。返回 dict(grid_text, cells, issues, header_rows)。
    占位规则（架构思考 §1-D4 已关闭缺陷）：空格目标区全部被上方合并覆盖 → 丢弃；
    空格落自由区 → 正常放置；非空格落入已覆盖区 → 记 overlap（真实错误）。"""
    trs = table_tag.find_all("tr")
    thead = table_tag.find("thead")
    header_rows = len(thead.find_all("tr")) if thead else 0
    grid, cells, issues = [], [], []
    for r, tr in enumerate(trs):
        while len(grid) <= r:
            grid.append([])
        c = 0
        for td in tr.find_all(["td", "th"]):
            while c < len(grid[r]) and grid[r][c] is not None:
                c += 1
            rs = max(1, int(td.get("rowspan", 1) or 1))
            cs = max(1, int(td.get("colspan", 1) or 1))
            text = re.sub(r"\s+", " ", td.get_text(" ", strip=True))
            if not text:
                occupied = sum(
                    1 for i in range(r, r + rs) if i < len(grid)
                    for j in range(c, min(c + cs, len(grid[i])))
                    if grid[i][j] is not None)
                if occupied == rs * cs:
                    issues.append({"kind": "placeholder_dropped", "at": [r, c]})
                    continue                      # 纯占位格，丢弃
            cells.append({"row": r, "col": c, "rowspan": rs, "colspan": cs,
                          "text": text, "bbox": None,
                          "is_header": bool(td.name == "th" or (header_rows and r < header_rows))})
            for i in range(r, r + rs):
                while len(grid) <= i:
                    grid.append([])
                while len(grid[i]) < c + cs:
                    grid[i].append(None)
                for j in range(c, c + cs):
                    if grid[i][j] is not None:
                        issues.append({"kind": "overlap", "at": [i, j]})
                    grid[i][j] = text
            c += cs
    n_rows = len(grid)
    n_cols = max((len(row) for row in grid), default=0)
    holes = sum(1 for row in grid for v in row if v is None) \
          + sum(n_cols - len(row) for row in grid)
    if holes:
        issues.append({"kind": "holes", "count": holes})
    return {"grid_text": grid, "cells": cells, "issues": issues,
            "n_rows": n_rows, "n_cols": n_cols, "header_rows": header_rows}
```

（命名澄清，本设计 J-5：此 `issues` 为**结构便签**（kind/at，如 placeholder_dropped/overlap/holes），与 §2.4 FR-E9 缺陷登记 `issues[]` 同名但不同语义——前者是展开过程的结构诊断，后者是缺陷台账记录；落盘时结构便签应转记至表 `adapter_notes`/诊断字段（与 §6.6 输出字段一致），不得混入 FR-E9 `issues[]`。）

#### 7.1.2 D2 过声明判定（本设计 §2.2 形式化；列向 + 行向）

```python
def overdeclare_info(table_tag):
    """过声明信息：dict(header_rows, col_D, row_over)。
    列向 D2：col_D = 表头格最大声明 rowspan − 表头 tr 数；
    行向 D2：row_over = 声明 rowspan 超出「锚行之后剩余 tr 数」的格清单。
    page_0087 兼有两者（本设计 §2.2）：thead 单 tr 内 th rs=2 → col_D=1；
    序号7 格 tr 位置 2、rs=11 而 max_tr=12 → 可覆盖 10 行 → 行向过声明 1。"""
    trs = table_tag.find_all("tr")
    max_tr = len(trs)
    thead = table_tag.find("thead")
    header_rows = len(thead.find_all("tr")) if thead else 0
    col_D = 0
    if header_rows:
        declared = [max(1, int(th.get("rowspan", 1) or 1))
                    for th in thead.find_all(["th", "td"])]
        col_D = max(declared, default=1) - header_rows
    row_over = []
    for r, tr in enumerate(trs):
        for td in tr.find_all(["td", "th"]):
            rs = max(1, int(td.get("rowspan", 1) or 1))
            avail = max_tr - r
            if rs > avail:
                row_over.append({"tr": r, "declared": rs, "available": avail})
    return {"header_rows": header_rows, "col_D": col_D, "row_over": row_over}
```

#### 7.1.3 过声明归一化（幻影行/列坍缩；粗架构 §11 遗留项，本版给出算法）

**统一算法**：把 rowspan 收缩到结构上界后再展开——列向收缩到表头行数、行向收缩到「锚行之后剩余 tr 数」。归一化无损（只改声明、不动数据），取代会丢数据的旧「删列」方案（删除被推入幻影列的首行数据格属数据破坏）。归一化结果**必须过守恒门**，不过则判定为未识别结构缺陷、整体入缺陷阶梯（需求书 §2.1-3 忠实优先）。

```python
import copy

def normalize_overdeclare(table_tag, cfg):
    """在深拷贝的 tag 上归一化 rowspan（保留原始 rs 证据，不就地变异）。
    返回 (expanded, notes)。notes 含 overdeclare_unresolved 前缀 = 归一化后仍不守恒。"""
    tag = copy.deepcopy(table_tag)
    trs = tag.find_all("tr")
    max_tr = len(trs)
    thead = tag.find("thead")
    header_rows = len(thead.find_all("tr")) if thead else 0
    notes = []
    # 1) 列向：表头格 rs 收缩到 header_rows
    if header_rows:
        for th in thead.find_all(["th", "td"]):
            rs = max(1, int(th.get("rowspan", 1) or 1))
            if rs > header_rows:
                th["rowspan"] = str(header_rows)
                notes.append(f"rowspan_overdeclare_col: {rs}→{header_rows}")
    # 2) 行向：任何格 rs 收缩到 max_tr − tr_index
    for r, tr in enumerate(trs):
        for td in tr.find_all(["td", "th"]):
            rs = max(1, int(td.get("rowspan", 1) or 1))
            avail = max_tr - r
            if rs > avail:
                td["rowspan"] = str(avail)
                notes.append(f"rowspan_overdeclare_row: tr{r} {rs}→{avail}")
    neo = expand_table(tag)
    if any(i["kind"] in ("holes", "overlap") for i in neo["issues"]):
        notes.append("overdeclare_unresolved: normalize 后仍不守恒")
    return neo, notes
```

### 7.2 M7：校验门四信号（FR-E8；第三轮方向裁决：信号3/4 降级为提示信号）

#### 7.2.0 总编排

**信号分层（第三轮方向裁决，需求书 FR-E8 v2.3 同步）**：四信号分两层——**gate-failure（否决）** = 结构校验（FR-E1）+ 守恒（FR-E2）+ 缺陷签名（D1/D2）+ 数值自洽（FR-E3），全部确定性、鲁棒，任一命中即入缺陷阶梯；**提示信号（hints）** = 交叉对位（信号3）+ 几何错位（信号4），基于本地 OCR 行盒、经 4 轮实证假阳率不可控，**不构成放行否决**，仅引导第二意见窄任务抽样（D3 终裁权在第二意见，本设计 §8.4）。此后全文「四信号任一命中即入阶梯」按「gate-failure 命中即入阶梯、hint 命中引导抽样」理解。

```python
def gate_check(table, ocr_lines, table_bbox, ocr_available, cfg, *, ocr_expected=True):
    """返回 {passed, failures, unavailable_signals, low_signal, hints}。
    failures = gate-failure（结构/守恒/签名/数值）；hints = D3 提示（信号3/4），不否决。
    ocr_expected=False 表示文字层确定性路径（method=textlayer）：信号3/4 为 N/A。"""
    failures, unavailable, hints = [], [], []
    # 入口守卫：退化 bbox 短路（本设计 MAJ-10 修复：零宽/零高 bbox 不参与坐标信号）
    degenerate = not table_bbox or table_bbox[2] <= table_bbox[0] or table_bbox[3] <= table_bbox[1]
    failures += sig_structure(table)                          # gate-failure：结构（FR-E1）
    failures += sig_conservation(table)                       # gate-failure：守恒（FR-E2）
    failures += sig_defect_signature(table, cfg)              # gate-failure：签名（D1/D2）
    low_signal = False
    if ocr_expected and ocr_available and not degenerate:
        cc_hints, cc_low = sig_cross_check(table, ocr_lines, table_bbox, cfg)      # 信号3 → hints（KD4）
        geo_hints, geo_low = sig_geometry_misalign(table, ocr_lines, table_bbox, cfg)  # 信号4 → hints（KD9）
        hints += cc_hints + geo_hints
        low_signal = cc_low or geo_low
    elif not ocr_expected:
        pass                                   # 文字层路径：信号3/4 N/A，非低信号（MAJ-R3-2）
    else:
        unavailable += ["cross-check", "geometry-misalign"]
        low_signal = True                      # 扫描路径 OCR 不可用 → 低信号（本设计 §7.2.5）
    failures += check_numeric(table)                          # gate-failure：数值自洽（FR-E3）
    return {"passed": not failures, "failures": failures,
            "unavailable_signals": unavailable, "low_signal": low_signal,
            "hints": hints}
```

def sig_structure(table):
    fails = []
    R, C = table["grid"]["n_rows"], table["grid"]["n_cols"]

        fails.append({"signal": "structure", "class": None,

#### 7.2.1 信号 1：守恒（FR-E2；提炼 evaluate.py 守恒逻辑）

```python
def sig_conservation(table):
    cells, R, C = table["cells"], table["grid"]["n_rows"], table["grid"]["n_cols"]
    seen, area, fails = set(), 0, []
    for cell in cells:
        r, c, rs, cs = cell["row"], cell["col"], cell["rowspan"], cell["colspan"]
        if r < 0 or c < 0 or r + rs > R or c + cs > C:
            fails.append({"signal": "conservation", "class": None,
                          "detail": f"越界({r},{c},{rs},{cs})", "cells": [[r, c]]})
            continue                                    # 越界格不再参与覆盖计算（MAJ-10）
        for i in range(r, r + rs):
            for j in range(c, c + cs):
                if (i, j) in seen:
                    fails.append({"signal": "conservation", "class": None,
                                  "detail": f"重叠({i},{j})", "cells": [[i, j]]})
                seen.add((i, j))
        area += rs * cs
    if area != R * C:
        fails.append({"signal": "conservation", "class": None,
                      "detail": f"不守恒 area={area}!={R}x{C}", "cells": []})
    return fails
```

#### 7.2.3 信号 3：交叉对位（KD4；**提示信号（hint）**，本设计第三轮修正版：空间归带 + 空间豁免 + 弃权不否决）

**角色（第三轮方向裁决）**：本信号为**提示信号（hint）**——输出 D3 疑似引导第二意见抽样，**不构成放行否决**（需求书 FR-E8 v2.3 同步，本设计 §7.2.0/§8.4）。其算法在现实 OCR 特性下假阳率不可控（经 4 轮实证），但作为 hint 假阳只消耗一次转写预算；其高召回（能命中真 D3）适合引导抽样。**行归表规则（定稿）**：OCR 行 box 的 y 中心 ∈ [table_bbox.y1, table_bbox.y2] 且行 box 与表块 x 区间交叠长度 / 行 box 宽 ≥ cfg.gate.row_assign_overlap（初值 0.5）→ 归表；**box 中心落入任一合并格空间区域的行剔除**（空间豁免，阻断-3）。**行带映射（第三轮修正）**：**均分归带**（`band = (yc−y1)/band_h` 钳制），不用聚类顺序映射。**比对对象**：只比对 **1×1 格**（rs=1 且 cs=1）的数值 token；合并格豁免为**空间判据**。**弃权纪律（阻断-1 修正）**：信号返回 `(hints, low_signal)`；映射失稳（网格有 token 而对应带 OCR 为空）置 low_signal、不产 hint。**数值比对**：行带内聚合 OCR 数值 token 与该带 1×1 格 token 多重集比较，不等即产出一条 D3 hint。

```python
import re, unicodedata

NUM_TOK = re.compile(r"[0-9０-９]+(?:[.,][0-9]+)*%?")

def norm_num(s):
    s = unicodedata.normalize("NFKC", s or "")
    return s.replace(",", "").replace("，", "").strip()

def sig_cross_check(table, ocr_lines, bbox, cfg):
    """返回 (hints, low_signal)。low_signal=True 表示映射失稳弃权（不否决，路由 §8.4）。
    hint 的 class：被合并格覆盖的行带 → "D3"；未被合并格覆盖的行带 → None（数值类，FR-E3
    口径，本设计严重-3）。"""
    x1, y1, x2, y2 = bbox
    if x2 <= x1 or y2 <= y1:
        return [], True
    R, C = table["grid"]["n_rows"], table["grid"]["n_cols"]
    col_w = (x2 - x1) / max(1, C)
    band_h = (y2 - y1) / max(1, R)
    # 合并格空间区域（用于空间豁免）
    merged_regions = []
    for cell in table["cells"]:
        if cell["rowspan"] > 1 or cell["colspan"] > 1:
            merged_regions.append((x1 + cell["col"] * col_w, y1 + cell["row"] * band_h,
                                   x1 + (cell["col"] + cell["colspan"]) * col_w,
                                   y1 + (cell["row"] + cell["rowspan"]) * band_h))
    merged_rows = {r for cell in table["cells"] if cell["rowspan"] > 1
                   for r in range(cell["row"], cell["row"] + cell["rowspan"])}
    def in_merged(xc, yc):
        return any(mx0 <= xc <= mx1 and my0 <= yc <= my1 for mx0, my0, mx1, my1 in merged_regions)
    rows_in = []
    for ln in ocr_lines:
        bx = ln["box"]
        yc = (bx[1] + bx[3]) / 2
        if not (y1 <= yc <= y2) or bx[2] <= bx[0]:
            continue
        overlap = max(0, min(bx[2], x2) - max(bx[0], x1))
        if overlap / (bx[2] - bx[0]) < cfg["gate"]["row_assign_overlap"]:
            continue
        if in_merged((bx[0] + bx[2]) / 2, yc):
            continue                                   # 空间豁免合并格（阻断-3）
        rows_in.append(ln)
    hdr = table["grid"].get("header_rows", 0)
    grid_rows = [[] for _ in range(R)]
    for cell in table["cells"]:
        if cell["rowspan"] != 1 or cell["colspan"] != 1:
            continue
        if not (0 <= cell["row"] < R):
            continue                                  # 越界格已由信号1记录（R3-A 建议-2）
        for tok in NUM_TOK.findall(norm_num(cell["text"])):
            grid_rows[cell["row"]].append(norm_num(tok))
    ocr_rows = [[] for _ in range(R)]
    for ln in rows_in:
        yc = (ln["box"][1] + ln["box"][3]) / 2
        b = min(R - 1, int((yc - y1) / band_h))         # 均分归带（阻断-2）
        for tok in NUM_TOK.findall(norm_num(ln["text"])):
            ocr_rows[b].append(norm_num(tok))
    hints, low = [], False
    for b in range(R):
        if b < hdr:
            continue
        g, o = sorted(grid_rows[b]), sorted(ocr_rows[b])
        if not g:
            continue
        if not o:
            low = True                                   # 网格有 token 而 OCR 空带：映射失稳，弃权（阻断-2）
            continue
        if g != o:
            cls = "D3" if b in merged_rows else None     # 未覆盖合并格 → 数值类（严重-3）
            hints.append({"signal": "cross-check", "class": cls,
                          "detail": f"行带{b} 数值不一致 OCR={o} GRID={g}",
                          "cells": [[b, -1]]})
    return hints, low
```

#### 7.2.4 信号 4：几何错位检测（KD9；本设计 MAJ-15 修正：列带过滤 + bbox 守卫）

**算法（纯几何，不读文本——与信号 3 算法层独立）**：①对每个 rs=k 合并格，取其 y 覆盖带；**排除合并格自身列带，在其余列中取「含数值 token」的 OCR 行**（D3 的错位值恰在数值列；序号列合并值不计——本设计 BLK-R2-1 修正：旧版按「只取合并格自身列」过滤，带内只剩合并值一行，语义反转致正确表必然误报），对 y 中心做一维聚类（容差 = 0.5 × 中位行高，`gate.geo_cluster_tol_line_h`，CALIB: MS-3）；聚类数 ≠ k 即命中（子行被压平/拆分）。②低信号判定：**某合并格无可计数的数值行（ys 为空）→ low_signal=true**（第三轮修正：不再复用已删除的 row_bands，且明确「无可计数证据即低信号」而非静默跳过，轻微-1）。③**角色（第三轮方向裁决）**：本信号为**提示信号（hint）**——产出 D3 疑似引导第二意见抽样，**不构成放行否决**（需求书 FR-E8 v2.3 同步），D3 终裁权在第二意见窄任务通道（本设计 §8.4 S2-R2）。**已知残余（诚实声明）**：列带用均分近似、数值列选择按「含数值 token」启发式，格内折行与子行间距相近时聚类数仍可能偏高——此类 hint 引导第二意见仲裁，不构成静默放行。

```python
def cluster_1d(vals, tol):
    vals = sorted(vals)
    clusters = []
    for v in vals:
        if clusters and v - clusters[-1][-1] <= tol:
            clusters[-1].append(v)
        else:
            clusters.append([v])
    return clusters

def sig_geometry_misalign(table, ocr_lines, bbox, cfg):
    x1, y1, x2, y2 = bbox
    if x2 <= x1 or y2 <= y1:
        return [], True
    R, C = table["grid"]["n_rows"], table["grid"]["n_cols"]
    in_tab = [ln for ln in ocr_lines
              if y1 <= (ln["box"][1] + ln["box"][3]) / 2 <= y2]
    heights = sorted(ln["box"][3] - ln["box"][1] for ln in in_tab) or [1]
    med_h = heights[len(heights) // 2]
    tol_y = cfg["gate"]["geo_cluster_tol_line_h"] * med_h
    col_w = (x2 - x1) / max(1, C)                    # 列带均分近似（CALIB: MS-3 校准）
    band_h = (y2 - y1) / max(1, R)
    hints, low = [], False
    for cell in table["cells"]:
        if cell["rowspan"] <= 1:
            continue
        cx0, cx1 = x1 + cell["col"] * col_w, x1 + (cell["col"] + cell["colspan"]) * col_w
        gy0, gy1 = y1 + cell["row"] * band_h, y1 + (cell["row"] + cell["rowspan"]) * band_h
        ys = []
        for ln in in_tab:
            xc = (ln["box"][0] + ln["box"][2]) / 2
            yc = (ln["box"][1] + ln["box"][3]) / 2
            if cx0 <= xc <= cx1:
                continue                             # 排除合并格自身列（只含合并值，BLK-R2-1）
            if not NUM_TOK.search(norm_num(ln["text"])):
                continue                             # 只取含数值行（D3 目标）
            if gy0 <= yc < gy1:
                ys.append(yc)
        if not ys:
            low = True                               # 该合并格无可计数数值行 → 低信号（轻微-1）
            continue
        k = len(cluster_1d(ys, tol_y))
        if k != cell["rowspan"]:
            hints.append({"signal": "geometry-misalign", "class": "D3",
                          "detail": f"合并格({cell['row']},{cell['col']}) rs={cell['rowspan']} 但数值列几何聚类行数={k}",
                          "cells": [[cell["row"], cell["col"]]]})
    return hints, low
```

| 状态 | 进入条件 | 动作 | 转出 |
| --- | --- | --- | --- |
| DETECTED | 校验门 **gate-failure** 命中（结构/守恒/签名/数值，确定性）/ FR-D1 自检命中 | 登记 issue（本设计 §2.4）+ old_text_snapshot | →RULE_FIX（有规则手段：D1/D2）→CROP（无规则手段：其他） |
| HINT | gate `hints` 非空（D3 提示）**或** low_signal=true（本设计 §8.4），**且** gate-failure 为空（否则先走 DETECTED） | **编排层 M12 承担**（不经 M8 `resolve()`）：调 M4.second_opinion_task 逐行转写（S2-R2），**复用 M8 的 _done/_marked 记账原语**（issue 登记、verified_by 追加 second-opinion、status 写回、预算闸前置）；对位一致且表内容无改动→**status=ok**，有改动→fixed，不一致/不可执行→uncertain（S2-R3/R4） | ok / fixed / uncertain |
| RULE_FIX | D1→规则拆分；D2→（适配层归一化已失败者不再重复） | 确定性修复，结果过校验门 | 过→FIXED；不过/误拆自检拦下→CROP |
| CROP | GLM 按表块 bbox 裁剪重译（FR-D4；去整页上下文） | glm_reparse_crop + 重过校验门 | 过→FIXED；不过且 retry 未用→RETRY；不过→SECOND；爆破→BLOWN |
| RETRY | FR-D8：仅一次定向重试，请求携带失败原因反馈（retry.seq=1，缓存指纹区分） | 同 CROP | 过→FIXED；不过→SECOND |
| SECOND | 第二意见窄任务（指定行/列转写；D3 逐行序号-数值转写为其传感器级独立通道） | second_opinion_task + strict schema + 行对位一致判定 | schema 不合→判失败；对位一致→FIXED；不一致→MARKED |
| MARKED | 全部手段耗尽 / 预算耗尽 / 无 key / egress_blocked | FR-E5：uncertain（打标到格）或 unreadable（附 reason，保原文） | 终态 |
| FIXED | 任一级修复后过校验门（gate-failure 修复）或第二意见行对位一致（D3 终裁） | status=fixed，verified_by 更新，issue.resolution 记录 | 终态 |
| BLOWN | finish_reason==length 或空 content 且已计费 | FR-D6：不自动重试、不分块、不降级输出；status=unreadable, reason=output_length_exceeded，入爆破表清单 | 终态 |

不变式（单元测试断言）：①RETRY 每表至多进入一次；②任何路径不得覆盖 pages[].text 原文与 old_text_snapshot；③MARKED/BLOWN 必带 reason；④每级调用先过预算闸（budget_exceeded → 直接 MARKED，reason 注明 budget）；⑤HINT 与 DETECTED 互斥——hints/low_signal 仅在 gate-failure 为空时触发直送 SECOND；**⑤第二款（本设计严重-4）**：gate-failure 与 hint 共存时先走 DETECTED 阶梯，但阶梯任一级修复后的重过门判据为 `passed ∧（扫描路径：hints 空 ∧ 非 low_signal）`，不满足则继续转 SECOND 执行 D3 窄任务——hint 不得因确定性修复成功而被静默丢弃。

#### 7.3.2 状态机代码骨架

```python
class Ladder:
    # 信号 → 缺陷类兜底映射（信号已带 class 时优先；本设计 BLK-5 修复）
    # 注（本设计轻微-3）：cross-check/geometry-misalign 已为 hint、不进 resolve()，此二项为
    # 历史死映射——禁止据此把 hint 接线回 resolve()（将复活已被第三轮裁决否决的「信号3/4 入阶梯」）。
    SIGNAL_TO_CLASS = {"signature": "D1"}

    def __init__(self, m4, gate, cfg, budget, ledger):
        self.m4, self.gate, self.cfg = m4, gate, cfg
        self.budget, self.ledger = budget, ledger

    def resolve(self, table, failure, ctx):
        issue = {"defect_class": failure.get("class") or self.SIGNAL_TO_CLASS.get(failure["signal"]),
                 "detected_by": [failure["signal"]], "resolution": "none",
                 "status": "unresolved", "detail": failure["detail"]}
        snap = table.setdefault("old_text_snapshot", flatten_text(table))
        state = "RULE_FIX" if self._has_rule_fix(failure) else "CROP"
        retried = False
        while state not in ("FIXED", "MARKED", "BLOWN"):
            try:
                if state == "RULE_FIX":
                    cand = rule_fix(table, failure, self.cfg)        # D1 枚举拆分/D2 已处理
                    if cand and self._passes(cand, ctx):
                        return self._done(table, cand, issue, "rule-split", "fixed")
                    state = "CROP"
                elif state in ("CROP", "RETRY"):
                    fb = failure["detail"] if state == "RETRY" else None
                    cand = self.m4.glm_reparse_crop(ctx["png"], table["bbox"],
                                                    hint=self._hint(failure, fb),
                                                    retry={"seq": int(retried),
                                                           "feedback_sha1": sha1_or_none(fb)})
                    cand = adapt_and_check(cand, self.gate, ctx)     # 适配+重过校验门
                    if cand["passed"]:
                        return self._done(table, cand["table"], issue,
                                          "crop-retranslate", "fixed")
                    if state == "CROP" and not retried:
                        retried, state = True, "RETRY"               # FR-D8 仅一次
                    else:
                        state = "SECOND"
                elif state == "SECOND":
                    res = self.m4.second_opinion_task(
                        ctx["png"], table["bbox"], vendor=ctx.get("vendor", "deepseek"),
                        task=self._narrow_task(table, failure))      # D3→逐行转写
                    if res["status"] == "ok" and rows_aligned(res["data"], table):
                        merged = merge_second_opinion(table, res)
                        if self._passes(merged, ctx):
                            return self._done(table, merged, issue,
                                              "second-opinion", "fixed")
                    state = "MARKED"
            except VisionError as e:
                if e.kind == "output_length_exceeded":
                    return self._blown(table, issue)                 # FR-D6
                if e.kind in ("budget_exceeded", "no_key", "egress_blocked"):
                    return self._marked(table, issue, f"degraded:{e.kind}")
                state = "MARKED"                                     # 其他视觉异常不猜
        return self._marked(table, issue, "exhausted")

    def _marked(self, table, issue, reason):
        # FR-E5：uncertain 打标到格；unreadable 仅爆破/渲染类
        unread = reason.startswith("output_length") or reason.startswith("render_")
        table["status"] = "unreadable" if unread else "uncertain"
        table["unreadable_reason"] = reason if unread else None
        mark_cells_uncertain(table, issue)                            # 格级打标
        issue.update(resolution="marked", status="unresolved", detail=reason)
        table["issues"].append(issue)
        return {"resolution": "marked", "table_out": table,
                "status": table["status"], "issues": table["issues"]}
```

### 7.4 M1：页内区域级探测（FR-A4；阈值定量初值，落实报告2-S2）

对 verdict=text 的文字层页执行。目标：发现文字层不可见的栅格表/栅格图区域，禁止整页走文字层而静默丢失。

```python
def detect_intra_regions(page, text_lines, cfg):
    """page: PyMuPDF page；text_lines: M3 行列表（pt 系）。
    返回 [{bbox_pt, kind, evidence}]。阈值（CALIB: MS-4 以 V-3 抽样真值校准）：
      min_region_area_ratio=0.04（区域面积/页面积）且 min_region_area_pt2=30000；
      text_cover_max=0.3（区域内被文本行覆盖比例上限，超则为文字区非栅格）；
      wire_h_min=6 条横线 且 wire_v_min=3 条竖线 → 线框特征判表。"""
    W, H = page.rect.width, page.rect.height
    regions = []
    # 1) 内嵌位图区域（栅格图/栅格表候选）
    for xref in {img[0] for img in page.get_images(full=True)}:
        for r in page.get_image_rects(xref):
            regions.append({"bbox_pt": [r.x0, r.y0, r.x1, r.y1],
                            "kind": "raster_image", "evidence": f"xref={xref}"})
    # 2) 线框矢量区（文字层页的矢量画线表）
    # PyMuPDF get_drawings() 的 path["items"] 元素为 ("l", p1, p2)/("re", rect, ...)——
    # 端点是 it[1]/it[2] 本身（Point），不是 it[1].p1/.p2（本设计 N-4 修正）。
    hz_lines, vt_lines = [], []
    for d in page.get_drawings():
        for it in d["items"]:
            if it[0] == "l":                          # ("l", p1, p2)
                p1, p2 = it[1], it[2]
                if abs(p1.y - p2.y) < 0.5:
                    hz_lines.append((p1, p2))
                elif abs(p1.x - p2.x) < 0.5:
                    vt_lines.append((p1, p2))
            elif it[0] == "re":                       # ("re", rect, orient) 矩形四边也计
                r = it[1]
                hz_lines += [(r.tl, r.tr), (r.bl, r.br)]
                vt_lines += [(r.tl, r.bl), (r.tr, r.br)]
    if len(hz_lines) >= cfg["intra_page"]["wire_h_min"] and \
       len(vt_lines) >= cfg["intra_page"]["wire_v_min"]:
        xs = [p.x for seg in hz_lines + vt_lines for p in seg]   # 两端点都收（bbox 不缩水）
        ys = [p.y for seg in hz_lines + vt_lines for p in seg]
        regions.append({"bbox_pt": [min(xs), min(ys), max(xs), max(ys)],
                        "kind": "raster_table",
                        "evidence": f"wires h={len(hz_lines)} v={len(vt_lines)}"})
    # 3) 过滤与判定
    out = []
    for rg in regions:
        x1, y1, x2, y2 = rg["bbox_pt"]
        area = max(0, x2 - x1) * max(0, y2 - y1)
        if area < cfg["intra_page"]["min_region_area_pt2"] or \
           area < cfg["intra_page"]["min_region_area_ratio"] * W * H:
            continue
        cover = text_cover_ratio(text_lines, rg["bbox_pt"])     # 行 bbox 交并比
        if cover > cfg["intra_page"]["text_cover_max"]:
            continue                              # 文字覆盖充分 → 非栅格盲区
        out.append(rg)
    return out
```

分流决策（留痕 metadata.routing[].intra_page_regions）：`raster_table` → 优先 GLM 裁剪解析（经 M4，计入出域开关与预算闸——粗架构 KD8 例外条款）；`--no-egress` 时 → M14 几何重建；两者都不可行 → 该区域记 `action=none` 并在页 note 诚实声明「未解析区域」。`raster_image` → M10 图片文件化。

def rebuild_wired(png_path, ocr_lines, cfg):
    """ocr_lines: [{box, text}]（M5 行级结果——本设计 MAJ-13 修正：几何重建用行级而非

### 8.2 V-4 共错率/不一致率（落实 s-1：统计单位与事件判定）

- **统计单位**：**对位单元 u = (page, grid_band, numeric_token)**（格级数值 token，按本设计 §7.2.3 行带归位）。页级与表级仅作汇总维度，不作判定单位（页级会稀释局部共错，token 级是双通道可比的最小语义单位）。
- **事件判定**：
  - 不一致事件 I(u)：归一化（NFKC、去千分位、去空白）后 GLM 网格 token ≠ 同行带 OCR token。
  - 共错事件 C(u)：u ∈ I 且以真值核对 GLM 错 ∧ OCR 错（相对真值各自判定）。**分母口径（本设计 MAJ-6 修正）**：共错占比 = |C| / |I_真值覆盖|，其中 I_真值覆盖 = 有真值可判的 I 子集——把真值缺失单元留在分母却不进分子，会使占比向「漏报共错」方向偏低（unsafe 方向），守门指标不得有此偏倚。
- **指标与阈值**：不一致率 = |I| / |U|；共错占比 = |C| / |I_真值覆盖|，并要求**最低真值覆盖率 |I_真值覆盖|/|I| ≥ 阈值（初值 80%，CALIB: MS-3 校准）**，不足则 V-4 前置门**不得判通过**（降级为「共错率未定，交叉对位按提示信号处理」）。**注（第三轮方向裁决）**：信号3/4 已**恒为提示信号**（需求书 FR-E8 v2.3 同步，本设计 §8.4），不再依赖共错率条件触发降级；`config.gate.cross_check_hint_only` 由此**退役**（语义被恒 hint 取代，MIN-R3-6 的开关诉求已被方向裁决满足）。V-4 共错占比的结果（≥50% 即「不可忽略」，需求书 §11 V-4 预设阈值）仍写入验收元数据 `metadata.v4_independence`，作为信号3 灵敏度的边界声明（hint 的可信度参考，非门禁开关）。
- **前置门**：先于 MS-3 出口（交叉对位取得放行权）完成（粗架构 MS-3）。**真值来源与时点**：对拍 4 页既有人工逐格真值（对拍报告 §4）+ 本设计 §9 L1 缺陷层真值（须在 MS-3 出口前完成生产，真值子集生产时点前移）。

### 8.3 V-5 RapidOCR 行级失效量化（落实 s-1 评估结论：**增设**）

- **动机**：V-4 只测 GLM↔OCR 相关性，不测 OCR 自身行级失效（报告3-B2 指出）；而 D3 双信号共享 OCR 行 box 上游，OCR 行分段失效是双信号同蒙的共因（报告2-R1）。
- **统计单位**：**行**（表块内 OCR 行 box）。
- **失效事件**：行合并（OCR 将两行并一行）/ 行拆分（一行拆两行）——操作化：表块内 OCR 行数 N_ocr 与参照行数 N_ref（GLM 网格行数，或真值行数优先）差异行数 / N_ref；辅以逐行带计数比对（本设计 §7.2.4 聚类数差异）定位。
- **判定与动作**：行级失效率 > 5%（CALIB: 本设计初值，MS-3 以真值子集校准）的表 → 标低信号区（同本设计 §7.2.4 low_signal），触发本设计 §8.4；全册失效率写入验收元数据，作为几何/交叉两信号灵敏度的边界声明。
- **执行**：与 MS-3 同批，复用本设计 §7.2.4 聚类设施，零额外视觉调用。

### 8.4 D3 检测与覆盖边界（落实 s-2；第三轮方向裁决：信号3/4 降级为提示信号）

**D3 检测架构（需求书 FR-E8 v2.3 同步；经 4 轮实证后由用户裁决）**：D3（无横线子行错位）无确定性检测手段（错位后仍守恒），其检测收敛到三层：

- **确定性信号（gate-failure，鲁棒）**：结构/守恒/签名/数值自洽——任一命中即入缺陷阶梯，覆盖 D1/D2 与结构缺陷，但**抓不住 D3**（错位后仍守恒）。
- **提示信号（hints）**：信号3 交叉对位 + 信号4 几何错位——基于本地 OCR 行盒，经 4 轮实证（含真实 RapidOCR + 忠实折行）在现实 OCR 特性下假阳率不可控，**降级为 hints**：不构成放行否决，仅引导第二意见抽样。作为 hint，其假阳只消耗一次转写预算、不造成误判；其高召回（能命中真 D3）使其适合引导抽样。
- **第二意见窄任务转写（传感器级独立，FR-D4）**：D3 的**终裁者**。受 hints、低信号区、V-5 触发的表，做逐行序号-数值转写，双通道行对位一致才放行。

**低信号区定义（仅扫描路径，method ∈ {glm-ocr, geo-rebuild}；本设计 MAJ-R3-2/N1 修正枚举）**：表满足任一：① 本设计 §7.2.3/§7.2.4 返回 low_signal=true（行带映射失稳弃权，或合并格无可计数数值行）；② V-5 判该表行级失效率 >5%；③ cross-check/geometry 两提示信号同时 unavailable（OCR 不可用**或表 bbox 退化致双信号不可得**，本设计轻微-4c）。**文字层确定性路径（method=textlayer）不适用本定义**——其信号 3/4 为 N/A 而非低信号，D3 缺陷类在该路径不存在（本设计 §2.3），该路径表凭结构+守恒+签名+数值自洽判 ok。

规则（仅扫描路径表）：

- **S2-R1（hint 不否决、必复核）**：hints 非空或低信号区的表，不得仅凭确定性信号判 ok 即终态；须触发第二意见窄任务转写复核（D3 终裁）。**status 单源化（本设计严重-5）**：第二意见对位一致且表内容无改动 → `status=ok`（verified_by 追加 second-opinion）；对位一致且按转写写回改动 → `status=fixed`；hint 为假阳时第二意见清空（表判 ok，成本为一次转写）。
- **S2-R2（低频抽样转写）**：触发第二意见窄任务**逐行序号-数值转写**（FR-D4 通道；**样本 = 序号/分组列全部 rs>1 合并组 ∪ hint 命中行带**，本设计严重-3 修正；若样本为空集——纯 1×1 表无合并组且无命中行带——按「不可执行」降级 uncertain，禁止空集 vacuous-pass）；双通道行对位一致才放行；受 Q13 复核预算闸约束（低频兜底定位，报告2-R1 建议 2）。
- **S2-R3（预算/无 key 降级）**：S2-R2 不可执行时，标 `status=uncertain`，`issues:[{defect_class:D3, detail:"d3_unverifiable_low_signal"}]`（低信号区表）或 `detail:"d3_unverifiable_hint"`（hint 阳性表，本设计轻微-4a），不覆盖原文。
- **S2-R4（显式不可达边界声明）**：`--no-egress`（含敏感文档强制本地）下的**低信号区 ∪ hint 阳性**表（本设计轻微-4b），D3 观测**不可达**——诚实声明为该表的已知未核验面：`status=uncertain`（打标到格，本设计严重-6）＋ `issues:[{defect_class:D3, detail:"d3_unobserved_no_egress"}]` ＋ 交付说明集中列清单。这是显式声明的不可达边界，不是静默通过；需求书 §7.1 台账捕捉率口径外缺陷由此声明覆盖（与需求书该条口径注解一致）。

## 9. 人工抽检真值子集（落实 s-3，自含规则）

需求书 §7.1「表格漏检率」与「缺陷台账捕捉率」口径外部分依赖人工抽检真值子集；本节自含其规模与选取规则（不依赖需求书单独外发）。

### 9.1 规模

每验收册 ≥20 页，构成：

| 层 | 选取规则 | 规模 |
| --- | --- | --- |
| L1 缺陷层 | 全部签名命中页 + 全部守恒失败页（**100% 入检，非抽样**；页内每表全入） | 全量（试点册口径：12 页签名命中 ∪ 10 页守恒失败，对拍报告 §8.2/§8.3；并集页数按页计） |
| L2 含表层 | 剩余含表页按固定随机种子 seed=20260906 抽取（抽样单位=页） | 入检含表页数 ≥ ceil(10 / 页均表数) 且 ≥ 全册含表页的 15% |
| L3 无表层 | 无表页随机抽（同种子） | ≥5 页（验漏检） |
| L4 特殊形态层 | 双栏/倾斜/页内混合（FR-A4）每类 | 各 ≥1 页（册内存在该类时；页内混合真值来源承 C-1：V-3 抽样或带真值合成页） |

**页⇄表换算口径（本设计 m-17/L-3 修正，统一以页为抽样单位）**：页均表数 = 全册检出表数 / 含表页数（试点册 = 73 表 / 73 含表页 = 1.0）。L2 生效下界取 `max(ceil(10/页均表数), ceil(0.15×含表页数))`——试点册 = max(10, ceil(0.15×73)=11) = **11 页**（旧「≥10 且 ≥15%」未取 max 的歧义已修正）。含表页定义：pages[].tables 非空的页。

试点册（180 页、73 表）预计真值子集 **≈ 31–41 页**（L1 并集理论区间 [12,22] 页，总区间 [31,41] 页；本设计 L-3/SUG-R3-1 修正，旧「≈25–35 页」估计偏低）；第 2/3 册 V-3 各抽 20 页时按同规则构成。
