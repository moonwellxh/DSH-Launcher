## 3. 接口签名（签名级；字段级留 Step 5）

### 3.1 M1 triage.py
```python
def triage(pdf_path, cfg) -> dict:
    """→ work/triage.json 内容：{file,page_count,encrypted,locked,
       degraded:{zero_page,blank_pages[]},pages:[{page,verdict,ratio,printable,
       cjk,layout_hint,skew_deg,dpi_ok,intra_regions:[...]}]}"""
    # 复用 pdf_text_probe：_printable_count/_cjk_count/verdict(0.50/0.30)
    # 新增：layout_hint(单/双栏)、skew_deg(>1.5° deskew)、intra_regions(FR-A4, 调 textlayer.detect_intra_regions)
class TriageError(Exception): ...   # .kind ∈ {encrypted, locked, zero_page}

# verdict 取值域与路由映射（S-1 修复，显式闭环）：
#   M1 页级 verdict（pdf_text_probe 原值域）: text | image | pseudo
#   → 路由词表（route_page 分支）: text | scanned | hybrid | unknown | skip_degraded
#   映射规则（M12.route_page 实现）:
#     text   → text（本地 textlayer）
#     image  → scanned（无文字层，走扫描/视觉路径）
#     pseudo → scanned（伪文本层：可读率<0.30，按扫描路径重路由，FR-A2 重路由语义）
#     unknown→ scanned（探测失败，保守路由，多花钱不丢信息）
#   文档级 verdict（triage.json 顶层）沿用 pdf-inspect 口径：
#     text/scanned/hybrid（hybrid=同册既有 text 又有 image/pseudo 页）；
#     页级 unknown 不阻止文档级 hybrid 判定。
```
- 异常：encrypted/locked/zero_page → TriageError + 编排层退出码 3（FR-A1）。
- **字段对齐冻结 §6.1**（吸收步3轻微-1）：含 `intra_regions`（FR-A4 输出不得丢）；`file/cjk` 作为附加字段保留无妨（冻结未禁止，标注"附加"）。

### 3.2 M2 render.py
```python

def px_to_pt(box, reg): ...
def pt_to_px(box, reg): ...
def crop_png(png_path, box_px, out_path, pad=8): ...   # 越界抛 RenderError(crop_degenerate)
def build_registry_entry(page, png, pdf_rect_pt, target_width) -> dict:

       其中 target_width=指定值；dpi 派生=round(pixel_w/pdf_rect_pt_w×72)；scale=pixel/pdf_rect_pt（逐轴）。
```

- **口径对齐冻结 §3.2 m-05（S-2 修复）**：target_width 为指定值、dpi 为派生值；登记恒满足 `dpi = round(pixel[0]/pdf_rect_pt[0]×72)`。config.render 现仅含 `dpi_default=220`（无 target_width），渲染按 dpi 档位驱动（resolution_steps），每次渲染以目标 dpi 反推 target_width 作为登记指定值——指定/派生在登记层面仍满足 m-05，不出现两值互斥。
- 渲染失败页 → RenderError 记日志、该页走本地 OCR 兜底 + 标记，不阻塞整册（冻结 §10）。

### 3.5 下游胶水接线声明（S-3 修复：复用 pipeline.py，不另起炉灶）

真 `<pdf>` 扫描路径下 M4→M6→M7→M8→M9 的串联胶水**已在 `assets/v4/pipeline.py` 实现**（`process_page_md(page_no, md, cfg, *, ocr_lines, ocr_available, m4, raw_resp)`：md_results→table_adapter.html_to_grid→gate_check→Ladder.resolve/resolve_hint→assemble_v4 收集；`acceptance_offline/run_fixture` 为其整册驱动）。orchestrator `run_pdf` 按下列复用（Step 7 编码据此落点）：
1. **扫描页单页链**：`render_page` 出页图 → `VisionClient.glm_parse_page(png, page, doc_sha1, render_reg)` 得结果 dict（含 `raw_response` 外层包装 `{http_status, latency_s, response, usage_extracted, ...}` 与顶层 `md` 便捷字段）→ **`pipeline.process_page_md(page_no, md, cfg, ocr_lines=..., ocr_available=..., m4=client, raw_resp=res["raw_response"]["response"])`** 产出 page part（含 tables/images）→ 收集。
   - **raw_resp 取值钉定（严重-1 修复）**：`process_page_md` 的 raw_resp 唯一消费点是 `_image_blocks`，其读 `raw_resp.get("layout_details")`——layout_details 在 **GLM response payload**（`res["raw_response"]["response"]`）内，不在外层包装 `raw_response` 上。故必须传 `res["raw_response"]["response"]`（与 `pipeline.run_fixture` L116-118 传 `raw.get("response")` 同口径）；若传外层 raw_response 则 layout_details 恒 None → images 恒空、图片索引静默丢失（FR-B6/S6）。md 参数同理取自 payload（`md = (res["raw_response"].get("response") or {}).get("md_results") or res.get("md_results") or ""`，Step 7 编码以 run_fixture 现有取法为准并加单测断言 images 非恒空）。
   - M5 调用点：`ocr_channel.ocr_pages(png_dir, cfg, out_json)`（整目录断点续跑）或 `ocr_page(png, engine, page)`（单页），产物 `{"pages":[{page,lines}]}` 经 `pipeline._load_ocr_lines` 语义喂入 process_page_md 的 ocr_lines。
   - M4 降级：`VisionError(no_key/egress_blocked/budget_exceeded/...)` → process_page_md 以 NoOpM4 语义（离线兜底）或按 FR-D7 诚实标记，不弹窗（页/表级）。
2. **文字层页**：`textlayer.textlayer_page(pdf, page_no, render_reg, cfg)`（模块已实现，产出即 page part，含 reroute 信号）。
3. **整册组装**：复用 `pipeline` 的 pages_parts 收集 + `structurer.assemble_v4(pages_parts=..., standard_info=..., transform_registry_ref=...)`（或 run_fixture 同款循环）→ M10 figures → M11 quality 台账 → 产物。
4. **离线验收路径不变**：`pipeline.acceptance_offline` / `tests/v4/run_acceptance.py` 继续可用（golden fixture），与 orchestrator run_pdf 并行不悖——pipeline 是"离线验收驱动 + 胶水库"，orchestrator 是"真 PDF 编排入口"，二者共享 process_page_md/assemble_v4。

### 3.4 数据流（承接细化任务书 §R-01 数据流，不变）

```
pdf → M1 triage → triage.json
  → 每页: text→M3 textlayer | scanned→M2 render(png+registry)→M4 GLM + M5 OCR
  → M6 适配 → M7 门 → M8 阶梯 → M9 structurer → M10 figures → M11 quality
  → out/<name>.v4.json + out/assets/ ; [--md/--html] → M13
```
