## 三、轻微级

### 轻微-1　R-01「pty 模拟真实终端」在目标执行环境（Windows Python）字面不可测，验收闭环有再次落空风险

- **anchor**：对象 §5 R-01（验收「pty 模拟真实终端选 C/B → exit2/1、留痕、无 v4 产物」）；§6.1（「R-01..R-13 各有可失败断言」）；§7 约束 2（「测试全离线可跑」）。
- **basis**：本机实测 `python -c "import pty"`（Python 3.12.10，Windows）在 `pty→tty→termios` 链上 ImportError——标准库 pty 在 Windows 不存在；而 CI 与全部 7 套离线测试均在本机 `python tests/v4/ci_all.py` 运行（SKILL.md §0.1 示例即 PowerShell 直跑）。实物 `test_orchestrator_pdf.py:139-140` 自认「subprocess 下 isatty False → 需用 pty 才为 True」并已退化为函数级 monkeypatch 模拟——这正是遗留 C-1 要补的缺口。对象未声明该测试的执行平台（POSIX/WSL）或替代判据（如 ConPTY 封装）；若 CI 维持 Windows 单机，R-01 将不可运行 → 被迫 skip（重演 C-4 已被批判的「空转跳过」反模式）→ §6.1「可失败断言」与 §7「全离线可跑」成空。
- **confidence**：high（环境事实为实测证据；影响判定为中——若规划 WSL/CI 平台则消解，但对象未声明）。

- **anchor**：对象 §3 目标 3（「优先真实 bbox 接线；若不可行则禁同页同 bbox 缓存命中」）；§5 R-13 与 §6.3 验收（「同页两张缺陷表构造夹具 → CROP/SECOND 指纹不同」）；§4 非目标/§7 约束均未涉及该路线性能或出域。
