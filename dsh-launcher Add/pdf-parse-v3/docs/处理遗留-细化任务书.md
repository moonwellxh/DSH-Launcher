## 0. 术语/口径（本步钉死）

- **公开参数**（doc-consistency 校验全集）：`<pdf> --out --no-egress --no-cache --md --html --pages --budget-glm --budget-review --ignore-gpu-lib`（**9 项**；轻微-1 收口：R-10 定 CLI 单一载体 --ignore-gpu-lib，故 8+1=9，SKILL.md §0.1 示例与 doc-consistency 同步加项）。
- **兼容内部参数**（argparse 有但不在 SKILL.md 示例/doc-consistency 全集）：`--page-image --page --render-reg-json --doc-sha1`。
- **TTY 判据**（R-01 钉死）：Windows 单机无 pty → 真实 TTY 端到端 POSIX-only；Windows 用函数级真实 input()（经替换 sys.stdin 喂入，非 monkeypatch 函数本身）+ finally 还原 stdin/isatty 覆盖 TTY 行为。
- **降档判据**（R-02）：唯一判据=registry.dpi < dpi_default（超 10MB 触降档）；**downsampled_from 裁决（轻微-2 收口）：不补登记字段、维持 None**——坐标链一致性由 dpi/scale 派生保证（m-05），验收即 dpi 唯一判据。
- **oversize 次序**（R-09）：先降档重渲再 OCR。**低档位机制（轻微-3 钉死）**：render_page 抛 oversize 已耗尽 cfg 档序（220/180/150）→ 重渲手段=render_page 增可选 `dpi_floor` 参数（Step 4 定实现）或档序列扩下限（如 [220,180,150,120]）；终止条件=产出 ≤10MB png 或达下限仍超限→诚实标记 reason=render_oversize；**不得仅标记即过**。
- **--pages 语义**（R-05，严重-1 修复后统一）：与 [1,page_count] 交集**非空** → 钳制到该交集（如 3 页 PDF 传 "1-10" → 处理 1..3）；交集**为空**（"5-10"或"4-5"于 3 页 PDF，均为全越界）→ **报错退出非 0**；无效 token（非数字/非区间）→ 报错退出非 0（"1,abc" 含非法 token = 整体无效报错，不静默取子集）；唯一合法空集形态=空串/未提供（=全量）。**禁空产物 exit0**（现行 _parse_pages 空集 falsy 全量产出、非法 token continue 吞——两者均改）。

## 1. 逐条细化（R-01..R-14 → 验收断言）

### R-01 弹选 TTY 交互测试（C-1/C-A5）
- **验收**：
  1. 函数级（机制钉死，轻微-6）：替换 `sys.stdin` 为 StringIO（喂 "3\n"）+ 真实 `builtins.input`（**非 monkeypatch input 函数本身**）→ `maybe_offer_degrade(reason,cfg,out,tty=True)` exit2 + chosen="C"；"无 v4 产物"断言**仅绑真实子进程用例**（函数级调用链不产 v4，恒真不做分母）。依赖注：调用签名含 cfg 依 R-08 同批改造先行——Step 6 排期 R-08 先于本用例落地，否则函数级用例先行 TypeError。
  2. 函数级：喂 "2" → exit1 + chosen="B" + stderr 含差异告知（"无网格表格重建"）。
  3. 非 TTY：真实子进程（stdin 非交互）→ exit3 + chosen=null + context="non-tty" + **无 v4 产物**（此处可失败断言）。
  4. 测试卫生（C-A5）：每个分支 finally 还原 sys.stdin/isatty 原对象（不再二次包 TextIOWrapper）。
  5. POSIX-only（可选，os.openpty 分支）：真实 TTY 端到端选 C → exit2；Windows skip（显式声明平台边界，行为已由 1/2/3 覆盖）。

## 3. 异常与边界（细化）

- 零页 PDF：R-03 用可构造路径触发（非空转）。
- --pages 交集空或含非法 token：报错非 0（禁空产物 exit0）；交集非空（含部分越界如 "1-10" 于 3 页）→ 钳制处理并产出（exit0）——"无效"一词仅指非法 token，与"越界（钳制）"两套分类不混用。
- TTY POSIX-only 测试：Windows skip 显式声明，行为由函数级覆盖。
- 表对位失败：回退退化 bbox + 页 note（诚实，不静默）。
