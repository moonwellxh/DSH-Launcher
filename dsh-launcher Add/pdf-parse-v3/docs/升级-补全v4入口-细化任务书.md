## 2. 逐条细化需求（R-01..R-08 → 验收口径）

### R-01 v4 CLI 真接 `<pdf>` 端到端
- **入口**：`python assets/v4/orchestrator.py <pdf> --out <dir> [--no-egress] [--no-cache] [--md] [--html] [--budget-glm X] [--budget-review Y]`——**对齐冻结《详细技术设计》§6.12 CLI 规格**（含 `--md/--html`，MD/HTML 仅显式触发 Q3）；`--md/--html` 接线既有 **M13 serialize_md.py/serialize_html.py**（模块已存在，本次兑现接线而非新造）。SKILL.md §0.1 现有 `--md/--html` 宣称与 orchestrator **MS-1 骨架态**实物不符，属待兑现缺口（与 `<pdf>` 拒收同一性质），升级后二者一致（见 D-1）。
- **数据流**（编排一次运行）：
  1. M1 triage → `work/triage.json`
  2. 逐页路由：text → M3 textlayer 本地；scanned → M2 渲染页图 → M4 GLM 整页 + M5 本地 OCR 校验；hybrid 逐页；退化输入（encrypted/locked/zero）优雅退出码 3
  3. 页/表结果 → M6 适配 → M7 门 → M8 阶梯 → M9 structurer 组装 → M10 figures → M11 quality 台账 → `out/<name>.v4.json` + `out/assets/`（图片库）+ `work/`
  4. 序列化（按需，仅 `--md/--html` 显式触发，Q3）：产物经 **M13 serialize_md/serialize_html** 输出 `.md`/`.html`（对齐冻结 §6.13）
- **验收口径**：
  - 文字层样件（整本）：exit 0；产物 schema_version=4.0；每页有 page part（text 或 lines[]）或诚实标记；无静默丢页（页数=PDF 页数断言）。
  - 扫描样件（前 N 页出域）：每页 routing.method=glm；台账 ledger 含 cost/usage；表 status∈{ok,fixed,uncertain,unreadable} 非空（**分母=检出表数，非空表数=0 时该断言按"检出 0 表"如实记录，不得空集给 1.0**）。
  - 重跑幂等：二次运行跳过已完成页（断点文件判断），产物与首跑一致。

### R-02 M1 triage.py
- **输入→输出**：PDF → `work/triage.json`：`{file, page_count, encrypted, locked, degraded:{zero_page, blank_pages[]}, pages:[{page, verdict, ratio, printable, cjk, layout_hint, skew_deg, dpi_ok}]}`。
- **复用**：pdf_text_probe.py 的 `_printable_count/_cjk_count/verdict`（阈值 0.50/0.30 常量沿用）；新增：layout_hint（单/双栏，调用 textlayer._detect_columns 口径）、skew_deg（文本行主方向，>1.5° 记 deskew，初值）、dpi_ok（PDF 页尺寸/目标渲染宽度合理性标记）。
- **异常与降级**：encrypted/locked → TriageError + 退出码 3；零页/全空白 → degraded 标记 + 退出码 3（FR-A1）；单页探测失败 verdict=unknown → 按 scanned 保守路由。
- **验收**：对文字层样件与扫描样件各跑一次：verdict 与 pdf-inspect 现判据一致（抽样页对照）；encrypted 模拟（若有夹具）退出码 3；triage.json 字段与 schema 一致（脚本校验）。

### R-03 M2 render.py
- **输入→输出**：PDF+页码清单 → `work/pages/page_NNNN.png` + `work/render/registry.jsonl`（每页一条登记：page/pdf_rect_pt/target_width/dpi/pixel/scale/render_sha1/downsampled_from）。
- **算法**：PyMuPDF `page.get_pixmap(matrix=Matrix(dpi/72, dpi/72))` 直渲（KD7）；dpi 初值 220，`resolution_steps=[220,180,150]` 超 10MB 降档重渲；坐标换算 `px_to_pt/pt_to_px/crop_png` 按设计书 §3.3（含 pad=8）。
- **异常与降级**：单页渲染失败 → RenderError(page) 记日志，该页走本地 OCR 兜底 + 标记（不阻塞整册）；降采样后仍 >10MB → 该页 GLM 路径 status=unreadable, reason=render_oversize，本地管线继续。
- **验收**：文字层样件抽样 3 页渲染 PNG 存在且非空、registry 字段齐全；`pt_to_px(px_to_pt(b))` 与 b 逐轴差 ≤1px 复算自检通过（≥10 随机 bbox）；10MB 降采样路径用合成超大页夹具断言触发。

### R-04 orchestrator 全流程编排
- **工作区布局**（断点即真相）：`work/{triage.json, render/registry.jsonl, pages/, glm/, ocr/, tables/, gate/, ladder/, figures/, ledger/, cache/}`。
- **编排链**：M1→逐页路由→（文字层：M3 textlayer，扫描页：M2+M4+M5）→M6 适配→M7 门→M8 阶梯→M9 组装→M10→M11→产物。
- **降级接线**（冻结语义，不重开）：视觉不可用（无 key/--no-egress/预算/断网）→ 该页/表自动本地兜底+诚实标记（FR-D7）；预算闸分通道（glm/second_opinion），超限停止该通道（BudgetGateStop）。
- **验收**：文字层整本端到端跑通；扫描样件 N 页跑通；断点续跑（中断重跑跳过已完成）；幂等（两跑一致）；`--no-egress` 下扫描页走本地兜底且标记可见（routing/issues 留痕）。

### R-05 整管线降级弹选（本次核心新需求）
- **触发条件（仅限）**：v4 全链结构性不可跑——M1/M2 模块缺失、编排入口抛结构性异常、依赖白名单不满足等**使 v4 无法形成产物**的情形。**不含**：无 key/--no-egress/预算超限/断网（=FR-D7 页/表级自动兜底，不弹窗）。
- **行为**：检测到结构性不可跑 → **中止并弹出选择项**（非静默）：
  - A：继续解决依赖后重跑 v4（用户修复后重发命令）；
  - B：用户显式确认降级 v3 旧管线，产出 v3.0 JSON，并**告知产物差异**（无网格表格重建/无图片索引/无 lines[] 坐标）；
  - C：取消。
  未选择不产出；仅选 B 才允许 v3.0 产物。
- **无 TTY/无人值守收敛（吸收复审轻微-1）**：stdin 非交互（CI/管道/批处理）时**不挂起等待**——行为＝中止 + 非零退出码 + 整管线级留痕（`work/degrade_choice.json` 记 `{trigger, reason, offered:[A,B,C], chosen:null, context:"non-tty"}`），**不产出、不静默降级 v3.0**；SKILL.md 同口径（代理层执行时同样必须先征询用户，不得自动选 B）。
- **SKILL.md/CLI 双落地**：CLI 层如上；SKILL.md 引擎决策表/分诊节补"整管线降级必询用户"条目。
- **验收**（可复测脚本断言）：
  1. 模拟结构性不可跑（如临时改名 M1 模块）→ 进程输出选择项且 exit≠0（TTY）或 exit 非零+留痕（非 TTY）；**无 v3.0 产物产生**。
  2. 非 TTY 下不阻塞（timeout 断言）。
  3. 选 B 路径（若有开关/注入）→ 才产出 v3.0 且含差异告知。
