## 1. 分级意见单（按严重度排序）

### 1.1 严重级（major，1 项）

#### R1 — 几何错位检测与交叉对位同源于本地 OCR，D3 的观测仍落在单一传感器上，「相互独立」被过度宣称（原 M3 未完全闭合）

- **anchor**：`需求确定书` FR-E8「几何行/列聚类错位检测（D3 第二观测信号，0-token 确定性，**与交叉对位相互独立**）」＋ 术语「几何错位检测：用**行 box** 的行/列聚类对齐性判定…」＋ 术语「交叉对位：**本地 OCR 行级识别结果**与表格数值按行对位…」＋ `技术设计文档` KD9「D3 **双独立观测信号**」。
- **basis**：扫描路径下 lines[] 的文本与 box **均出自 RapidOCR**（FR-B1「扫描路径坐标双源——GLM 块级 bbox 为主体 + 本地 OCR 行四点 box」，交叉对位与几何聚类共用的是其中「本地 OCR 行 box」这一路）。D3 的失败模式恰是「无横线子行错位」——若 RapidOCR 把该子行并入相邻行（行分段共错），文本对位与几何聚类会**同时**失效，两个信号无法互为冗余。原报告 M3 的核心诉求是「风险最高的缺陷类不要落在唯一且最不可靠的传感器上」，本次修复只是对同一 OCR 输出做了「文本特征 vs 几何特征」的二次分析，属**特征级冗余、非传感器级冗余**。
- **confidence**：high（「相互独立」过度宣称成立）；medium（几何信号对 D3 的实际灵敏度，须待实测）。
- **type**：逻辑 / 边界（控制论根基）。
- **suggestion**（二选一或并行，须在详细设计前写死）：
  1. 把「几何错位检测」明确定义为**跨源几何比对**：GLM 块 bbox 几何 ↔ 本地 OCR 行 box 几何（FR-D2 已有「GLM 块 bbox 与几何定位互为校验」的现成基础），并将「相互独立」降级为「特征独立（文本 vs 几何）＋跨源比对」；
  2. 把**第二意见窄任务「逐行序号-数值」转写**明确列为 D3 的**传感器级独立通道**（低频兜底，受 Q13 复核预算闸约束），与 FR-D4 现有第二意见机制合并表述。
  3. 实证前，KD9「双独立观测信号」措辞降级为「双特征观测，独立性待 V-4/V-5 实证」；同时保留「单信号可疑即 uncertain 不放行」的降级口径（该口径本身正确，予以确认）。
