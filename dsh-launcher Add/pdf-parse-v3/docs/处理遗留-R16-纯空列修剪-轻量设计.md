## 1. 判据/算法（G-1 修复：守卫与删除/左移规则显式化）

`_trim_empty_cols(tb)`（在 `html_to_grid` 每表 tb 组装后、`_infer_header_rows` 之前调用）：

- **全空列**：列 c 无任何单元格文本（cells 中任一覆盖到 c 的 cell（含 colspan 扩展）文本均空）→ 且该表仍有非空列（全空表保护不剪）。
- **保守跳过（G-1 修复）**：仅当存在 cell 满足 `colspan>1 且其区间 [col, col+colspan) 同时含`保留列`和`被删空列``（横跨空列与保留列边界）→ 整表跳过修剪（记录残余）。**单列空列内、colspan=1 或跨度全在空列集内的 cell 不触发跳过**（这些格文本必空，按删除处理）。
- **删除/左移规则（G-1 修复，显式）**：对每个 cell：
  - 若其区间 `[col, col+colspan)` 与空列集**无交** → 保留，`col` 按 old→new 映射左移（colspan 不变）；
  - 若其区间 `⊆ 空列集`（跨度全在被删空列内，含 colspan=1）→ **删除该 cell**（文本空、无信息）；
  - 若 `colspan>1 且跨保留+空列边界` → 整表跳过（见上保守跳过，此分支实际不执行）。
- **重算 holes（G-2 修复）**：修剪后重算该表 `holes`（基于 cells 重建覆盖网格，计数未覆盖格（None）），并**同步覆写** `adapter_notes` 中的 `holes@N` 便签：旧 `holes@old` 删除，新 `holes@new`（new=0 则不加）；否则快照/diff/断言（以 adapter_notes 为 holes 事实源）无法反映修剪效果。
- R-15 表头推断不受影响（按 tag 原始行判定，与列数无关）；overdeclare 归一化分支（neo 表）同样处理。

## 4. 断言（tests/v4/test_ms2_replay.py 追加；S-1 覆盖左移/跨列场景）

- 合成"幽灵尾空列"表（正常表头+数据，尾部补一整空列）→ `n_cols==有效列数`、`holes==0`（修剪+重算生效，覆盖左移）。
- 合成"跨空列 colspan"表（某 cell colspan 跨到空列）→ **整表跳过**（n_cols/holes 不变，保守残余）——覆盖守卫跳过分支。
- 合成"全空表"（`<tr><td></td><td></td></tr>`）→ 保护不剪（n_cols 不变）。
- 真实夹具：`page_0085` 修剪后 `n_cols==5`/`holes==0`（或其空列被移除）；`page_0095` 全空表 `n_cols` 不变（保护）。
