## 1. 背景与问题陈述

现有链路（pdf-parse-v3，Schema v3.0）已能完成：分诊（文本/扫描/混合）→ 引擎路由（PyMuPDF 版式 / RapidOCR / WinRT）→ 章/条/表题/图说结构化 → 逐页溯源 JSON。存在三类未闭合的缺口：

| # | 缺口 | 性质 |
| --- | --- | --- |
| G1 | **表格结构缺失**：扫描件表格只有 caption，单元格数据未重建；JSON 中无 rowspan/colspan/网格坐标 | 信息重建问题（PDF→JSON 段断裂） |
| G2 | **图只有"说"没有"体"**：figures 仅存图说文字，图本体未文件化入库，无法原位还原显示 | 信息承载不完整 |
| G3 | **无下游保真出口**：JSON 之后没有标准化的 MD/HTML 序列化；朴素拼管道表会把复杂表"读错"（数字与列名静默错位） | 表达能力问题（JSON→MD 段断裂） |

主路线的工程可行性已经实测确立（2026-09-06，GBJ16-87 第 1 册 180 页全量）：专用文档解析模型 GLM-OCR（智谱 API，0.9B［来源：《视觉与文档解析API选型调研》§C1］）整册解析 **100% 成功、表格零漏检、86.3% 结构守恒直通、总成本 ¥0.1615、单页均时延 4.25s**；输出 Markdown 内嵌 HTML 表格（rowspan/colspan 准确）、版面块级坐标与类型、公式 LaTeX。其缺陷全部位于"结构映射"层且可自动检测（详见 §5-E 校验门与 §5-D 缺陷阶梯）。对照组通用视觉模型（Qwen3-VL-Flash）文字读取良好但复杂表网格结构 0/4 不守恒，证实专用模型路线的必要性。

## 2. 设计原则

### 2.1 第一性原理锚点（不可让渡）

**系统的唯一使命：把任意 PDF 承载的信息，完整、忠实、可溯源、可还原地转移到机器可消费（JSON）与人可阅读（MD/HTML，按需）的形态。**

推论：

1. PDF 一页的信息形态只有三类：**文字、表格、图**。任何一类在某环节断供，都是系统级缺陷。
2. 无损链路的充要条件：**中间表示的表达力 ≥ 源文档结构复杂度**，且每个转换器在其表达力范围内做保真映射。
   - 对表格：网格模型（n_rows × n_cols + 每格 row/col/rowspan/colspan/text/bbox/角色）是与 HTML 表格表达力等价的**最小完备模型**，必须作为 JSON 层的表格基准表示。
   - 对图：图本体是位图，保真的做法是**整体切出、文件化、JSON 只存索引**。
3. 忠实优先于结构：**解析失败时保留原文并诚实标记，禁止为凑结构而错拆、禁止静默覆盖原文**。
4. 可溯源：任何结构化元素可双向定位（内容 ↔ 物理页 ↔ 页内坐标）；坐标链必须在各表示间确定可换算。

### 2.2 控制论系统结构

把整条链路视为**被控对象 = 信息保真度**的反馈控制系统。结构原则：**执行通道可以单一，观测与纠偏通道必须冗余且相互独立**。

| 控制论角色 | 系统中的对应物 |
| --- | --- |
| 前馈控制 | 分诊（先测后读，按承载形态选引擎） |
| 传感器 | 规则/几何自检；校验门（守恒 / 缺陷签名 / 交叉对位 / 几何错位检测四信号）——规则与几何信号 0-token、确定性、可复算；交叉对位依赖本地 OCR，属本地零费用但非严格确定性（模型版本敏感、CPU 耗时），以固定模型版本 + 样本固化保证可复算 |
| 控制器 | 路由与升级决策（总是先走成本最低且充分的手段；升级条件显式） |
| 执行器 | 文本引擎 / GLM-OCR 整页解析（扫描主通道）/ 本地 OCR（校验通道，默认开启）/ 几何重建 / 第二意见视觉模型 |
| 反馈与校正 | 校验 → 缺陷阶梯（规则修复 → 裁剪重译 → 第二意见复核）→ 标记；校正有界（规则修复单表限一轮；定向重试限一次 FR-D8；第二意见仅限校验门检出的缺陷表窄任务调用，且受分通道预算闸 FR-D5 约束）；**v2.3 注**：hint/低信号区表（D3 疑似）不经裁剪重译，直送第二意见窄任务转写（FR-E8 v2.3） |
| 安全态 | 诚实标记 + 原文保留：任何失败收敛到安全态而非猜测态 |
| 必要多样性（Ashby） | 文档形态多样性（文字/扫描/混合 × 各类表格复杂度）由引擎多样性匹配；双通道互为校验的前提是误差模式互不相关——该独立性为**待实证假设**（V-4：以既有对拍样本量化 GLM 与本地 OCR 的不一致率/共错率，结果作为提示信号灵敏度元数据；交叉对位/几何错位 v2.3 起**恒为提示信号**，见 FR-E8） |
| 可观测性 | 修复报告、缺陷台账、token 台账、验收指标 |

## 3. 总体目标与非目标

### 3.1 总体目标（一句话）

**任意 PDF（文字版 / 扫描版 / 混合；适用边界以 §8 为准——加密、超大页数、多语种、手写体、公式等按 §8 与 §3.3 显式排除或降级）→ 可溯源结构化 JSON（文本 + 网格表格 + 图片索引三形态完备）+ 附件图片库；JSON 是默认唯一产物，Markdown（复杂表局部内嵌 HTML 表格）与 HTML 仅在用户明确要求时生成；全流程全自动，失败诚实标记，成本可预算。**（v2.4 修订：**全自动**指正常路径与页/表级视觉兜底（FR-D7 自动）；**整管线结构性降级须经用户选择，是唯一人工交互例外**（FR-A5，见 §3.3-2 与 §5-A）。）

### 3.2 目标（In Scope）

1. PDF → JSON：三形态完备承载，表格升级网格模型，图片文件化入库并原位锚定。**默认产物到此为止。**
2. JSON → MD（按需，用户指令触发）：按表格复杂度分级序列化；图片原位引用。
3. JSON → HTML（按需，用户指令触发）：自包含可读页面（表格原生渲染、图片原位、溯源信息可查看）。
4. 表格结构重建与缺陷闭环：GLM-OCR 整页解析（扫描件主通道）→ HTML→网格适配 → 校验门 → 缺陷阶梯 → 诚实标记。
5. 质量与成本的可观测：修复报告、缺陷台账、token 台账、验收指标。

### 3.3 非目标（Out of Scope，显式排除）

1. 无框线且已完全失真的老扫描表 100% 还原（承认上限，以诚实标记收敛）。
2. ~~任何需要人工点选/交互的流程~~（v2.4 修订：页/表级全自动——FR-D7 视觉不可用自动本地兜底+诚实标记，不弹窗；**整管线结构性降级（v4 全链不可跑时）须先弹选择项、用户选择后才能降级，禁止无感降级——唯一人工交互例外 FR-A5**；人工仅在失败清单层面事后介入的表述仅适用于正常路径与页/表级兜底）。
3. 本机 GPU 重型 VLM 的默认启用（仅留接口文档，本期不实装）。
4. 图的像素数据内联进 JSON（base64 内联明确禁止；图为文件 + 索引）。
5. 公式识别（LaTeX 化）、手写体、多语种（>中英）——本期不做，但数据模型不得堵死后续扩展。
6. RAG 切分、检索服务等下游应用本身（本系统只保证产物可被下游正确消费，含读取方协议）。
7. MD/HTML 的主动生成（无用户明确要求时不生成；生成能力内置待命）。

## 4. 系统路线（最终态）

```
任意 PDF
  → 分诊（text / scanned / hybrid / 退化输入探测 / 页内区域级探测，判定依据落盘可复核）
  → 逐页路由：
      [文字层] 本地确定性提取（版式坐标引擎：逐行 bbox/字号/阅读序）
                输出可读率过低（疑似伪文本层）→ 自动改道扫描路重跑本页
      [扫描页] GLM-OCR 整页解析（MD 全文 + HTML 表格 + 块级 bbox/类型 + 公式 LaTeX）
                + 本地 OCR 行级识别（校验通道，默认开启）
      [混合] 按页走上述两路之一
      [页内混合] 文字层页内检出疑似栅格表/图区域 → 该区域追加 GLM 裁剪解析或几何重建
  → 表格适配层：HTML→网格模型（占位空 td 丢弃、幻影列坍缩、跨页续表合并）
  → 校验门：守恒检查 + 缺陷签名 + 交叉对位 + 几何错位检测（四信号，全自动）
  → 缺陷阶梯：规则修复 → 裁剪重译 → 第二意见复核 → 诚实标记（不覆盖原文）
  → 章节条文结构化（本地确定性逻辑，输入为干净有序文本）
  → 图片文件化（数字版抽内嵌原图；扫描页按块 bbox 裁剪）+ 索引
  → v4.0 JSON（默认唯一产物）
  → [按需] MD / HTML 生成
```

## 5. 功能需求（FR）

> 编号规则：FR-<域><序>。域：A 分诊与路由 / B 内容提取 / C 表格结构重建 / D 缺陷修复阶梯 / E 校验与诚实标记 / F 输出序列化 / G 工程纪律。
> 优先级：P0 必须 / P1 应当 / P2 可选。

### A. 分诊与路由

| 编号 | 需求 | 验收要点 | 优先级 |
| --- | --- | --- |:---:|
| FR-A1 | 读任何 PDF 前先分诊：text / scanned / hybrid，判定依据与抽样结果须可复核（落盘）；零页/全空白页等退化输入须优雅报错不崩溃 | 分诊报告含每抽样页可读率与判据；退化输入有测试 | P0 |
| FR-A2 | 引擎路由表显式化：文字层→本地版式坐标引擎；扫描页→GLM-OCR 整页解析 + 本地 OCR 校验通道（默认开启）；混合→逐页路由；路由决策写入产物 metadata；**重路由反馈**：文字层路径输出可读率过低（疑似伪文本层）时自动改道扫描路径重跑该页，改道留痕 | metadata 含每页 method；重路由路径有测试 | P0 |
| FR-A3 | 版式与质量前置探测：单/双/混栏、倾斜（deskew 需求）、DPI 充分性，探测结果参与后续算法参数选择 | 页级版面标记；倾斜页清单 | P1 |
| FR-A4 | **页内区域级探测**：以文字层覆盖率 + 页内图像块/线框检测识别「页内混合」（文字层页含栅格表/栅格图区域）；疑似栅格表区域追加 GLM 裁剪解析或 FR-C2 几何重建，禁止整页走文字层而静默丢失该区域 | 页内混合样例的检出与追加解析有测试；分流决策留痕 | P1 |
| FR-A5 | **整管线结构性降级须用户选择（v2.4 新增，禁止无感降级）**：v4 全链结构性不可跑（模块缺失/依赖白名单不满足/编排入口断裂，无法产出 v4）时，不得静默改走更低能力管线/旧 schema——先弹选择项（A 解决依赖重跑 / B 显式降级并告知产物差异 / C 取消），**未选择不产出、仅用户选 B 才允许降级**；非交互（CI/管道）环境：中止 + 非零退出码 + 留痕（degrade_choice.json），不产出、不静默降级。**页/表级视觉不可用（无 key/--no-egress/预算超限/断网）属 FR-D7 自动本地兜底+诚实标记，不弹窗** | 结构性降级弹选/非 TTY 中止有测试；degrade_choice.json 留痕字段齐全 | P0 |

### B. 内容提取（三形态采集）

| 编号 | 需求 | 验收要点 | 优先级 |
| --- | --- | --- |:---:|
| FR-B1 | **行级坐标必须入 JSON**：文字层路径写入词/行 bbox；扫描路径坐标双源——GLM 块级 bbox 为主体 + 本地 OCR 行四点 box（默认开启，作交叉对位与字高几何估计）；约定 `pages[].lines[]={box,text}`，box 高≈行字高可作字号几何估计 | JSON 含 lines[]；box 坐标系声明完整 | P0 |
| FR-B2 | **坐标变换登记**：渲染 DPI/TargetWidth/像素尺寸与 PDF 页尺寸统一记录，保证 JSON bbox ↔ 页图 crop 确定可换算 | 给定 bbox 可程序复算裁剪区 | P0 |
| FR-B3 | 老数据兼容：无 box 的历史 JSON 标记 `locatable=false`，走整页回退路径，不得假装有坐标 | 兼容读取测试通过 | P0 |
| FR-B4 | **图片文件化抽取（全类型默认开启）**：数字 PDF 优先抽内嵌原图（保原始分辨率；矢量图按区域重渲染）；扫描件按版面块 bbox 裁剪（GLM image 块定位为主，几何法为兜底）；小图/装饰过滤阈值可配（默认阈值试点册标定后写死） | assets/ 落盘 + 索引字段完整；重复图按 hash 去重 | P0 |
| FR-B5 | **图/表先分类再分流**：表格走 FR-C 重建，图片走 FR-B4 入库；禁止把表格误裁成图片 | 分流决策留痕；误裁率纳入验收 | P0 |
| FR-B6 | 图注关联：邻近图注正则关联入 caption；对裁出图可再跑 OCR 得 ocr_text 供全文检索 | 索引含 caption/ocr_text | P1 |

### C. 表格结构重建（PDF→JSON 段的一等公民）

| 编号 | 需求 | 验收要点 | 优先级 |
| --- | --- | --- |:---:|
| FR-C1 | **网格模型为表格基准表示**：`{n_rows,n_cols,cells:[{row,col,rowspan,colspan,text,bbox,is_header}]}`，与 HTML 表达力等价；合并、多级表头、格内换行均可表达 | 守恒检查 Σ(rowspan×colspan)=n_rows×n_cols 恒可通过 | P0 |
| FR-C2 | 线框表几何重建（GLM 主路线中的离线确定性兜底与校验手段）：形态学线段检测→网格聚类→缺失线段=合并推断→词块按中心点归格、被覆盖格路由回锚点 | 合成复杂表（纵横合并+格内换行）结构 100% 还原 | P1 |
| FR-C3 | 文字层表格用确定性提取（pdfplumber find_tables 等），结果同样过 §5-E 校验 | 提取结果映射为网格模型后无错列 | P0 |
| FR-C4 | 无线框表（三线表等）：x/y 坐标聚类推断行列；不足时升级 FR-D，不硬猜 | 无框表进入修复阶梯的判据显式 | P1 |
| FR-C5 | 跨页续表识别与合并：表头列数匹配 + "续表/单位/序号连续"信号；合并需标注来源页区间 | 续表合并后守恒且页区间可溯 | P1 |
| FR-C6 | **GLM HTML→网格适配层**：将 GLM-OCR 输出的 HTML 表格确定性转换为 FR-C1 网格模型；含占位空 td 丢弃规则、幻影列坍缩启发式、缺陷签名标注；转换结果必过 §5-E 校验门 | 整册 73 表转换验证；占位格规则复测有效；坍缩后再过守恒 | P0 |

### D. 缺陷修复阶梯（校验门命中后的处理链）

> GLM-OCR 是扫描件主解析器；本组是校验门检出的缺陷表/格的修复链。复核执行器为 GLM 裁剪重译 + 第二意见模型（DeepSeek / Qwen3-VL-Flash 文本复核）。多模型接口抽象延后（多厂商客户端基座复用既有资产，新增供应商时再扩展）。无 key / 无额度 / 超预算时按 FR-D7 自动降级，不阻塞全流程。

| 编号 | 需求 | 验收要点 | 优先级 |
| --- | --- | --- |:---:|
| FR-D1 | **0-token 自检**：对 JSON 逐表/逐页按显式信号（有表题无结构、表格压平、疑似续表、数字自洽破坏、特殊字符密集、版式断裂）产出 suspicious_tables[]，含 page/caption/bbox/reasons/old_text_snapshot | 候选结构字段完备；信号可复算 | P0 |
| FR-D2 | **定位优先几何规则（0-token）**：用 FR-B1 行 box 聚类判定表块（行列对齐/行距均匀/数字密度/边界跳变），输出表块 bbox + locatable；GLM 块 bbox 与几何定位互为校验 | 定位不消耗 token；回退路径存在 | P0 |
| FR-D3 | 传统手段优先于视觉复核：几何重建/规则修复能解则解，结果同样过校验门 | 传统手段命中率计入报告 | P0 |
| FR-D4 | **视觉复核（第二意见通道）**：对校验门检出的缺陷表/格——先 GLM 按块 bbox 裁剪重译（去整页上下文干扰）；仍不过则送第二模型窄任务复核（指定列/行的文本转写）；双通道行对位一致才放行；输出严格 Schema（status/data/rowspan/colspan/header_rows/confidence/issues）。**v2.3 注**：hint/低信号区表（D3 疑似）不经裁剪重译，直送第二意见窄任务转写（FR-E8 v2.3；本设计建议-1） | 输出不合 Schema 直接判失败；对位不一致不得写回 | P0 |
| FR-D5 | **token 治理**：预算以实测 usage 为准（禁止用官方计算器推算；GLM 实测单页 prompt 页级区间 444–4585 tokens（对拍难例 4 页 3571–4211）、约 ¥0.0009/页［口径：对拍报告 §3 ＋ batch_ledger.jsonl 全量复算，台账最大 4585=page_0079］）；参数集中化（型号/价格/max_tokens/分辨率档位/预算上限）；按指纹缓存结果，重跑不重复计费；**第二意见通道设独立预算闸**：单册视觉总预算按通道分解（GLM 主通道与 DeepSeek·Qwen 复核通道各自封顶），DeepSeek 峰谷价差从提示升级为可配置封顶 + 超限自动降级 | 台账含每表/每页 prompt/completion tokens；分通道预算台账 | P0 |
| FR-D6 | **爆破定位**：输出被截断（finish_reason==length 或空 content）且已计费时，不自动重试、不分块、不降级输出；记 `status=unreadable + reason=output_length_exceeded`，生成爆破表清单供定向重跑 | 爆破清单字段完备 | P0 |
| FR-D7 | 视觉不可用时（无 key/无额度/超预算/断网）视觉环节自动降级为"本地管线 + 诚实标记 + 跳过"，不阻塞全流程 | 降级路径有测试 | P0 |
| FR-D8 | **普通校验失败的一次定向重试**：未过校验门且非爆破类失败时，允许且仅允许一次定向重试（重试请求可携带失败原因反馈）；仍不过则按 FR-E5 标记、不覆盖原文；与 FR-D6（爆破不重试）分工显式 | 重试次数≤1 且台账可审计 | P0 |

### E. 校验与诚实标记（反馈与安全态）

| 编号 | 需求 | 验收要点 | 优先级 |
| --- | --- | --- |:---:|
| FR-E1 | 结构校验：行列一致（含合并展开）、非空行>0、Schema 合规 | 不合规不得写回 | P0 |
| FR-E2 | **守恒检查**：Σ(rowspan×colspan) == n_rows×n_cols，不等即结构自相矛盾 | 自动执行并入报告 | P0 |
| FR-E3 | 数值自洽（可解析时）：合计=分项和、序号连续、单位不串位；与页原文交叉校验关键数字（防幻觉数值） | 幻觉数值不得通过 | P0 |
| FR-E4 | 表头跨页一致性：续表合并时表头列数对齐校验 | 错列续表被拒 | P1 |
| FR-E5 | **标记协议**：每表 `status∈{ok,fixed,uncertain,unreadable}` + method + confidence + verified_by + issues；uncertain 仅打标到格；unreadable 附 reason 且保原文不覆盖 | 标记字段完整率 100% | P0 |
| FR-E6 | **读取方约定**：凡 status ∉ {ok,fixed}，下游不得把该表（格）数值当事实；引用必须声明不可信。此约定写入产物文档与交付说明；生成 HTML 时以角标呈现（默认开，可关） | 文档条款存在；交付物含该声明 | P0 |
| FR-E7 | TEDS 评估接口（可选）：有标注数据时按 TEDS 打分；无标注时以 FR-E1~E4 + 抽检替代，不虚构指标 | 接口存在；无标注路径明示 | P2 |
| FR-E8 | **校验门四信号（v2.3 起分两层）**：**gate-failure（否决）** = 结构校验（FR-E1）+ 守恒检查（FR-E2）+ 缺陷签名检测（合并格拼接签名、幻影列特征，D1/D2）+ 数值自洽（FR-E3），全部确定性、鲁棒，任一命中即入缺陷阶梯；**提示信号（hints）** = 交叉对位（本地 OCR 行级文本与表格数值对位，默认开启）+ 几何行/列聚类错位检测（D3 第二观测信号，0-token 确定性；与交叉对位为算法层独立，但同源于本地 OCR 行 box，传感共因为已知残余——传感器级独立通道为第二意见窄任务转写，FR-D4）——经实测假阳率不可控，**不构成放行否决**，仅引导第二意见窄任务抽样；**D3 终裁**在第二意见窄任务转写（双通道行对位一致才放行）；**D3 降级口径**：hint/低信号区表不经确定性信号直接放行，须触发第二意见转写复核；仅单一信号可疑且无法复核时不得自信放行，按 FR-E5 标记 uncertain | 守恒/签名/交叉对位三信号已有整册实测捕获记录；几何错位检测捕获记录待 MS-3 补齐；交叉对位/几何错位假阳率已经 4 轮实证确认不可控（故降级为 hint） | P0 |
| FR-E9 | **缺陷登记与台账**：每表 issues[] 登记 {defect_class, detected_by, resolution, status}；全册产出缺陷台账（页→缺陷→处理结果）；**缺陷不允许静默通过** | 台账字段完备率 100%（硬性） | P0 |

## 6. 数据模型需求（方向性，细节留待技术设计）

1. **Schema 版本升级 v4.0**：表格从 `data[][]`（或仅 caption）升级为 FR-C1 网格模型；图片从"仅图说"升级为"索引块 + 文件"；页文本升级为含 lines[] 坐标层。`data[][]` 列入废弃清单（新文件不生成；需要时可从网格退化导出）；旧版本文件不强制迁移，读取方按版本分支。

4. **图片索引块**（与文本块平级、锚定阅读顺序）：`{type:"image", id, page, path, bbox, hash, caption, ocr_text/alt}`。

## 13. 术语表

| 术语 | 定义 |
| --- | --- |
| 网格模型 | 表格的基准表示：n_rows × n_cols + 每格 {row,col,rowspan,colspan,text,bbox,is_header}，与 HTML 表格表达力等价 |
| 守恒检查 | Σ(rowspan×colspan) == n_rows×n_cols；不等即结构自相矛盾，不得写回 |
| 校验门 | 对每张表自动执行的四信号检查，v2.3 起分两层：gate-failure（结构/守恒/缺陷签名/数值自洽）任一命中即入缺陷阶梯；提示信号（交叉对位/几何错位）不构成放行否决、仅引导第二意见；D3 终裁在第二意见窄任务转写，仅单一信号可疑且无法复核时降级 uncertain |
| 缺陷签名 | 已知缺陷类的确定性特征模式（如合并格内"汉字紧跟数字"的拼接签名、幻影列特征），可正则检测 |
| 交叉对位 | 本地 OCR 行级识别结果与表格数值按行对位核验；D3（无横线子行错位）观测信号之一，与几何错位检测互为冗余；其对 GLM 的误差独立性以 V-4 共错率实证为准 |
| 几何错位检测 | 用行 box 的行/列聚类对齐性判定子行错位的 0-token 确定性信号（D3 第二观测信号；行 box 扫描路径来自本地 OCR，与交叉对位共享上游，传感共因为已知残余） |
| 缺陷阶梯 | 缺陷处理链：规则修复 → 裁剪重译 → 第二意见复核 → 诚实标记；逐级升级、不覆盖原文 |
| 幻影列 | 表头 rowspan 过声明导致首行数据被推入的多余网格列 |
| 爆破定位 | 视觉输出被 max_tokens 截断的检测与登记机制（不重试、记 unreadable、入爆破清单） |
| 出域 | 文档内容离开本机发送到云端 API |
| TEDS | 树编辑距离相似度，表格结构识别的标准评测指标 |
| 分诊 | 解析前判定 PDF 承载形态（text/scanned/hybrid）并据此前馈选引擎 |
| 续表 | 跨页延续的同一张表；需识别、合并并标注来源页区间 |
