## 四、建议级

### 建议-5　首格抽查的探测覆盖面与修复文句保证不符：首格相同而后续错位仍会静默错配 bbox；且跨语料首格转述差异将令合法有序页整页退化

- **anchor**：对象 §2 R-13（L287-296 首格抽查+整页回退、L302 声明「跨语料 count 等而序错位时诚实回退，不静默错配 bbox」）。
- **basis**：抽查只比每个配对表的**首格**。若两表首格相同（续表/同表头型：如双表页两表首格均为「序号」/「名称」类），count 等而序互换时首格全部相等→抽查通过→错配 bbox 仍静默发生，与 L302 的"不静默错配"保证相抵触（我实测 page_0019 双表首格分别为「液化石油气储罐」「名称」，同表头场景在语料外真实存在形态）。另一面：语料外合法有序页若 md/layout 首格因转述差异不同，整页 bbox 会被误判 order-mismatch 退化（保守丢真坐标）。整表归一化文本相等（即预研 order_ok 口径）比首格更强且同成本，可同时闭合两缺口；本机 180 页全过不产生新误伤。
- **confidence**：medium（序错概率不可测；机制覆盖缺口与文句保证的差集为确定性推演）。

### 建议-6　R-07 OOM 护栏的数学表述不成立：两组独立上限（请求宽 ≤6000px ∧ pdf 高 ≤2400pt）不蕴涵"首候选像素 ≤ ~30Mpx"

- **anchor**：对象 §2 R-07 ⑦（L185 括号内「首候选上限 ≤6000px、pdf 高 ≤2400pt 的 OOM 护栏，首候选像素 ≤ ~30Mpx」）。
- **basis**：首候选像素=请求宽²×(页高 pt/页宽 pt)。两上限不含页宽下限：页 1000×1200pt+6000px → 6000×7200=43.2Mpx>30Mpx；页 600×2400pt+6000px → 6000×24000=144Mpx（RGBA≈576MB），护栏声明的"≤~30Mpx"不成立。当前夹具（≤1000×1200pt×≈4000px→19.2Mpx）本身安全，缺陷在把"夹具实际值安全"表述成"护栏约束普遍成立"。
- **confidence**：high（纯算术反例，确定性）。

### 建议-7　R-07 ⑦ 终态可达性依赖候选最末档与噪声像素预算联动，文内未钉 ⑦ 的 cfg（resolution_steps/dpi_floor）

- **anchor**：对象 §2 R-07 ⑦（L185 断言终态 png≤10MB、dpi<dpi_default）与 §2 R-09 断言 c（L229「cfg resolution_steps=[220]+floor 96」共用密度夹具）。

- **confidence**：medium（噪声 PNG 尺寸为量级推演，含校准项；参数缺省组合下不可达为确定性）。
