### R-05 --pages 语义 + MockM4（S9-A1/A2）
**产品（orchestrator.py）**
```python
_PAGE_TOKEN_RE = __import__("re").compile(r"(\d+)(?:-(\d+))?")

def _parse_pages(spec, page_count):
    """→ (list[int]|None, err|None)。None/空串=(None,None) 全量（唯一合法空集形态）。
    逐 token 截交 [1,page_count] 后再入集（防 '1-999999999' 类合法 range 膨胀，建议-1）；
    任一 token 非法/区间逆序→报错（不取子集）；截交后为空→报错（整 spec 交集空）。"""
    s = spec.strip() if spec is not None else ""
    if not s:
        return None, None
    out = set()
    for part in s.split(","):
        p = part.strip()
        m = _PAGE_TOKEN_RE.fullmatch(p) if p else None
        if not m:
            return None, "无效页码 token：%r（支持 '1-10'/'1,3,5'）" % p
        a, b = int(m.group(1)), int(m.group(2) or m.group(1))
        if b < a:
            return None, "页码区间逆序：%r" % p
        lo, hi = max(a, 1), min(b, page_count)
        if lo <= hi:
            out.update(range(lo, hi + 1))
    inter = sorted(out)
    if not inter:
        return None, "页码范围 '%s' 与 1..%d 交集为空" % (s, page_count)
    return inter, None
```

### R-07 render target_width 降档（C-5）
**算法定稿（两分支，保缺省路径行为 100% 不变）**
```python
def render_page(pdf, page_no, out_dir, cfg, target_width=None, dpi_floor=None):
    ...  # 前段：rect/非法尺寸/档序构造（dpi_steps 含 default 优先、去重保序，与现一致）
    def _attempt(dpi_val, tw):
        # 渲染 → ≤10MB 返回 registry；超限/失败返回 None（失败记 last_err）
        ...
    if target_width is None:                        # 分支 A（缺省，registry.dpi=档值——行为不变）
        for dpi_val in dpi_steps:
            if _attempt(dpi_val, w_of(dpi_val)): return reg
        if dpi_floor is not None and float(dpi_floor) < float(dpi_steps[-1]):
            if _attempt(float(dpi_floor), w_of(float(dpi_floor))): return reg
    else:                                           # 分支 B（target_width 指定——降档候选序列）
        cands = [int(target_width)]
        for d in dpi_steps:
            cw = w_of(d)
            if cw < cands[-1]: cands.append(cw)
        if dpi_floor is not None:
            fw = w_of(float(dpi_floor))
            if fw < cands[-1]: cands.append(fw)
        for tw in cands:
            if _attempt(round(tw * 72.0 / pdf_w, 4), tw): return reg
    if last_err: raise last_err
    raise RenderError("oversize", "page %d 全档位（含 dpi_floor）仍 >10MB" % page_no)
```

- 断言（test_render ⑦）：**独立夹具（不复用 R-02 ≥5000pt 密铺，避免首候选位图 OOM——轻微-3 修复）**：中尺寸页（≤1000×1200pt）整页嵌入 PIL 随机噪声位图（insert_image 全页，高熵、PNG 难压缩），`target_width` 请求 ≈4000px；**OOM 护栏（建议-6 修复）**：首候选及各档候选像素数 `w_px×h_px ≤ 3×10^7`（h_px 按同 dpi 由 pdf 高换算），夹具与请求宽度参数以满足该不等式为前置并在测试内断言；流程=首候选渲染 >10MB（**有效性前置断言**）→ **可达性前置（建议-7 修复）**：断言至少一梯档候选（如 150 档）噪声 png ≤10MB（保证终态可达非恒失败）→ 断言终态 `reg["target_width"] < 请求值`、`reg["dpi"] < dpi_default`、png ≤10MB；**m-05 物理口径断言（建议-3）**：`abs(reg["pixel"][0] / pdf_w * 72 - reg["dpi"]) <= 0.5`（以 pixel 反算，防 scale/实渲像素漂移；弃"tw 同式双写"近似恒真式）。全部数值为校准点（噪声种子/尺寸），以本地实测固化。

**产品（pipeline.py）**
```python
def _layout_table_blocks(payload):
    """layout_details[0] 中 native_label=='table' 的块，保序返回 [(bbox_int4, content_html)]。
    bbox_int4=[x1,y1,x2,y2]（像素系，int）；content_html 供首格抽查（轻微-5 修复：消费端需 html 做 _first_cell_eq）。"""
    out = []
    for page_blocks in (payload or {}).get("layout_details") or []:
        if not isinstance(page_blocks, list):
            continue
        for b in page_blocks:
            if not isinstance(b, dict):
                continue
            if (b.get("native_label") or b.get("label")) != "table":
                continue
            bb = b.get("bbox_2d") or [0, 0, 0, 0]
            out.append(([int(bb[0]), int(bb[1]), int(bb[2]), int(bb[3])], b.get("content") or ""))
    return out
```
- process_page_md 在 `tables = html_to_grid(md, cfg)` 后：
```python
    lay = _layout_table_blocks(raw_resp)
    unresolved = None
    if tables and len(lay) == len(tables):
        # 逐位抽查（建议-2 收口）：md 表首格 与 layout 块 HTML 首格 归一化相等或双空 → 对位可信
        mismatch_i = next((i for i, tb in enumerate(tables)
                           if not _first_cell_eq(tb, lay[i][1])), None)   # lay[i]=(bbox, html)

    elif tables:
        for tb in tables:
```
