## 1. 目标（一句话）

**把 v4 从"下游完备、入口缺失、宣称超前"修复为真正可用的端到端管线：`python orchestrator.py <pdf> --out <dir>` 即产出 v4.0 JSON（网格表格+图片索引）+ 附件图片库；引擎/能力不足时禁止无感降级，整管线降级显式征询用户，页/表级局部兜底自动并诚实标记。**

## 3. 目标（In Scope）

1. **M1 triage.py**：改造 `assets\pdf_text_probe.py` → 分诊输出 `work/triage.json`（页数/encrypted/locked/degraded/逐页 verdict+ratio+layout_hint…），退化输入优雅报错不崩溃。
2. **M2 render.py**：PDF+页码 → `work/pages/page_NNNN.png` + `work/render/registry.jsonl`（变换登记/10MB 降采样/FR-A4 按需渲染），编排内 PyMuPDF `get_pixmap()` 直渲（设计书 §6.2 处置偏离：ps1 不再承担数据流）。
3. **orchestrator.py 升级**：真接 `<pdf>`；编排 M1→M2→逐页路由（文字层→textlayer 本地路径；扫描页→M4 GLM + M5 本地 OCR 校验；混合逐页）→M6 适配→M7 门→M8 阶梯→M9 组装→M10 图片文件化→M11 质量台账→v4.0 JSON+图片库；MD/HTML 按需（M13）；预算闸、`--no-egress`、断点续跑、幂等（设计书 §6.12 规格落地）。
4. **引擎降级显式化（新需求，经用户裁决修订上游 §3.1/§3.3-2）**：整管线能力结构性不可用（如 v4 全链缺模块不可跑）时**禁止静默改走 v3 旧管线/旧 schema**——先弹选项由用户确认（继续解决依赖 / 显式降级并告知产物差异 / 取消），**未选择不产出**；页/表级视觉不可用维持自动本地兜底+诚实标记（FR-D7，不弹窗）。**与上游 §3.1「全流程全自动」的关系（S-2.3 显式界定）**：上游"全自动闭环"指正常路径与页/表级兜底自动化；"整管线结构性不可跑的降级选择"是本升级经用户裁决新增的**唯一人工交互例外**，v2.4 修订稿将在 §3.1/§3.3 同步此界定，消除内部矛盾——本文第 4 条第 6 项"不弹窗化页/表级兜底"即为此边界的镜像（两处不冲突，弹选仅限整管线级）。
5. **SKILL.md §0.1 修正**：CLI 用法与代码一致、模块清单与实物一致（无虚构 render(M2) 条目，改列真实入口）、补降级弹选口径；分诊/引擎决策表同步（含"降级前必询用户"）。
6. **测试与文档**：既有四套离线测试（ms1/ms2/ms3/ms5）保持全绿；新增 M1/M2/orchestrator 单测；文档链就地增量（需求书 v2.4 / 设计 v1.2）。

## 6. 验收指标框架（细化任务书定口径，可失败、真分母）

1. 文字层样件：整本 PDF 端到端，产出一份 v4.0 JSON + 图片库；无静默丢页（每页有产物或诚实标记）。
2. 扫描样件：GLM 出域真跑 N 页，每页 routing.method=glm、台账记 cost/usage；表 status 非空。
3. 降级弹选（整管线级）：在"v4 全链结构性不可跑（如 M1/M2 缺失、编排入口断裂）"的模拟下，管线**不得**静默改走 v3 旧管线/产出 v3.0 schema；必须暂停并**弹出选择项**（选项 A 继续修复依赖后重跑 v4 / 选项 B 用户显式确认降级 v3.0 并告知产物差异 / 选项 C 取消），用户选择后方可继续——用可复测脚本断言（无选择不产出）。**页/表级视觉不可用（无 key / --no-egress / 预算超限 / 断网）不属于本条**：维持冻结设计 FR-D7 的自动本地兜底+诚实标记，不弹窗（与需求书 v2.3 FR-D7、设计 §10 一致，不重开冻结决策）。
4. 回归：既有四套离线测试 + 新增单测，CI 一键全绿；hash 数值比对等真实断言（无假绿灯）。
5. 文档-实物一致性：SKILL.md 所列 CLI 与模块清单逐项对得上实际文件（脚本校验）。

## 7. 约束（沿用冻结文档，仅列出本次相关）

- 密钥只读 `%USERPROFILE%\.config\pdf-parse-v3\keys.json`，不随产物外发；`--no-egress` 可全局短路。
- 单机 CPU 基线、无 GPU 假设；依赖白名单沿用（pymupdf/pypdf/pdfplumber/rapidocr_onnxruntime 等）。
- 含中文脚本 UTF-8 BOM；数据/文档 UTF-8 无 BOM；幂等不覆盖原文；进度读磁盘产物。
- 任何降级/异常在 routing/issues/note/metadata 留痕（可观测性，不静默）。
