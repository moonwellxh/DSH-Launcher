  4. 冻结 R-05 ①“结构性不可跑→…exit≠0（TTY）”。设计对“选 A”`return 0`（退出码 0）与该“exit≠0”口径需澄清（测试用选 C 绕开，见轻微-5）。

## 三、轻微（Minor）

### [轻微-1] run_pdf 局部代码的 `stem` 未定义与 `textlayer_page` 未 import

- **anchor**：§3.2 L281、L302-303。
- **basis**：如上，`stem` 与 `textlayer_page` 均为 NameError 源；虽属“可随手补”的局部笔误，但作为“详细设计局部代码”应无此类可直接复制即坏的缺陷。见严重-3，此处单列以明确数值。
- **confidence**：高。

### [轻微-2] triage 恒设 `layout_hint="single"`、`dpi_ok=true`，与冻结 R-02/FR-A3 冲突且未声明

- **anchor**：§1.2 L106。
- **basis**：冻结《细化任务书》R-02 要求“layout_hint（单/双栏，调用 textlayer._detect_columns 口径）”，冻结《需求确定书》FR-A3（版式与质量前置探测）依赖 layout_hint/dpi_ok 做后续算法参数选择。设计直接写死“single/true”，未调用 `_detect_columns`（textlayer.py L46 为空白实现），也未列入 §6 占位声明 → 与冻结要求冲突。建议补“Step 7 调 textlayer._detect_columns”或明示占位。
- **confidence**：中。

### [轻微-3] §1.3 声明“单页探测异常→verdict=unknown”，§1.2 未实现该分支

- **anchor**：§1.3 L132 与 §1.2 L97-115。
- **basis**：§1.3 说“单页探测异常 → verdict=unknown，不中断；doc_verdict 忽略该页”。但 §1.2 循环 `t = page.get_text() or ""`（L98）外层无 try/except，某页抛异常即整循环崩溃，无法置 unknown。且 §1.2 注释“raw==0→image（verdict 同）”正确，但 unknown 处理缺失。建议补 per-page try，或声明该分支留 Step 7。
- **confidence**：中。

### [轻微-4] 用 PyMuPDF `get_text()` 提取喂 pypdf 口径 `verdict`，一致性风险

- **anchor**：§1.2 L98-103 与 L42 复用声明。
- **basis**：`ptp.verdict/_printable_count/_cjk_count`（pdf_text_probe.py L37-72）其输入本为 pypdf `extract_text()` 口径（probe main L156-167）。设计改用 fitz `get_text()`，两引擎提取结果可能不同 → ratio/verdict 有偏差；冻结 R-02 验收“verdict 与 pdf-inspect 判据一致（抽样对照）”可能失配。建议统一用 pypdf 或明示“按 fitz 口径、以自测覆盖”。
- **confidence**：中。

### [轻微-5] `main` 返回 int 但无 `sys.exit(main())` 封装，退出码不传播

- **anchor**：§3.1 L242-258。
- **basis**：`main(argv=None)` 内 `return 2`/`return 3`，设计未给出 `if __name__=="__main__": sys.exit(main())`。当前 orchestrator 用 `raise SystemExit`/裸 `main()`（orchestrator.py L165-166）。若照设计仅 `main()`，返回值不进进程退出码，R-05 验收“exit≠0”、测试②“exit2/exit3”无法达成。建议显式 `sys.exit(main())`。
- **confidence**：高。

### [轻微-6] 文字层 `render_reg_for` 未定义且“无 PNG 建登记（供坐标换算）”细节缺失

- **anchor**：§3.2 L280 与 §2.2 `render_page`、textlayer.py L76-120。
- **basis**：`textlayer_page` 需 `render_reg["scale"]`（textlayer.py L67-69 pt_to_px）。设计对 text 页调用未定义 `render_reg_for(rec,cfg)`，亦未说明“不渲染 PNG 时如何构造含 scale 的登记”。文字层坐标换算无依据。建议补 `render_reg_for` 定义或复用 m-05 派生式。
- **confidence**：中。

## 四、建议（Suggest）

### [建议-1] §2.2 渲染档位构造方式需澄清

- **anchor**：§2.2 L175。
- **basis**：`steps = [cfg.render.dpi_default(220)] + cfg.render.resolution_steps[1:]` 依赖 `dpi_default == resolution_steps[0]`（config.default.json 两者恰为 220），否则产生意外档位。建议显式“去重后按序取档”（如 `sorted(set(resolution_steps), reverse=True)`），避免隐含耦合。
- **confidence**：高。

### [建议-2] 逐页 FR-A2 重路由后顶层 `doc_verdict` 未同步

- **anchor**：§3.2 L282-283 与 §1.2 L116。
- **basis**：`doc_verdict` 由 triage 一次性判定（L116）。若某 text 页在 run_pdf 中被 FR-A2 重路由为 scanned（L283），顶层 `doc_verdict` 仍按初判保留，与“hybrid＝既有 text 又有 image/pseudo 页”判据可能不一致。建议在重路由时同步更新 doc_verdict 或明示以 triage 时点为准。
- **confidence**：中。

### [建议-3] §4.2 未明说《详细技术设计》v1.2 存档 v1.1

- **anchor**：§4.2 文头（L378-388）。
- **basis**：§4.1 明说“新文件，存档 v2.3”，§4.2 未对应说明存档 v1.1；冻结 R-08 验收“存档文件保留”。建议 §4.2 补“存档 v1.1”一句，保持两表对称。
- **confidence**：中。
