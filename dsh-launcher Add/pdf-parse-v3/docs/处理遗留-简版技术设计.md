### R-05 --pages 语义实现（S9-A1/S9-A2）+ MockM4 严格化

- **产品重写 `_parse_pages(spec, page_count)`**（返回 `(sorted_range|None, err|None)`；None=全量）：
  1. 空串/None → (None, None)（全量，唯一合法空集形态）；
  2. 逐逗号 token，正则 `^(\d+)(?:-(\d+))?$` 校验；**任一 token 不匹配 → (None, err="无效页码 token：X")**（"1,abc" 含非法→整体报错，不取子集）；
  3. 全部合法 → 并集 U；`U ∩ [1,page_count]` 为空 → (None, err="页码范围与页数无交集")（"5-10"/"4-5" 于 3 页同构）；
  4. 交集非空 → 返回钳制交集（"1-10"→1..3；"1,5-10"→{1}——**仅整 spec 交集空才报错，不按段报错**）。
- 调用点：`run_pdf` 在 triage 成功（拿 page_count）后解析；err → stderr + **return 2**（无产物落盘，v4 文件写回在尾段天然不触发）；成功 → 过滤 tri["pages"] 与页循环（替代现 L323 预解析）。
- **断言（六例，3 页 PDF）**：正常 "1-3"→exit0 3 页；部分越界 "1-10"→exit0 产物 3 页；全越界 "5-10"→exit非0 无 .v4.json；无效 "abc"、"1,abc"→exit非0 无产物；混合 "1,5-10"→exit0 产物 1 页；空串/缺省→全量 3 页。
- **MockM4（test_ms3_ladder）**：`second_opinion` 改与生产同形——`page/doc_sha1/render_reg` **必填**（去默认），并加记录器字段（captured page/doc_sha1/render_reg），用例断言收参与 ctx 期望一致（补 S9-A1 转发守卫）。

### R-07 render target_width 降档（C-5）

- **算法（重构 L58-90 候选序列）**：
  - 请求宽度 `req_w` = `target_width`（指定时）或 `round(pdf_w×dpi_default/72)`（缺省）；
  - 候选宽度序列 = `[req_w] + [round(pdf_w×s/72) for s in dpi_steps if round(...) < 上一候选]`（严格递减去重；缺省时即原 dpi 档序行为不变）；
  - 逐候选渲染，首个 ≤10MB 即登记返回：`target_width=实际宽度、dpi=round(实际宽×72/pdf_w,4)`（**m-05 两向保持**：指定值=dpi 派生；降档后按实际候选登记，不再每轮重算同一 dpi）；
  - 全候选超限 → `RenderError("oversize")` 不变。
- 断言（test_render 新增）：同 R-02 密度夹具 + `target_width=round(pdf_w×220/72)` 之上再放大（如 3×default 宽）→ 不抛 oversize、终态 `reg["target_width"] < 请求值`、`reg["dpi"] < dpi_default`、png ≤10MB、m-05 复算一致（`abs(reg.dpi-round(tw×72/pdf_w)) ≤ 0.5`）。

### R-09 oversize 次序（C-8）

- **dpi_floor 机制（定）**：`render_page(pdf, page_no, out_dir, cfg, target_width=None, dpi_floor=None)`——缺省档序（220/180/150）全超限且 `dpi_floor` 提供且 `< 已试最低档` 时，**以 floor 为最低 dpi 再试一次**；仍 >10MB → 抛 `RenderError("oversize")`（语义不变，不做无底降档）。registry 字段不变（downsampled_from 仍 None）。
- 产品 `_scan_page_local`：渲染与 OCR 解耦：
  1. `try: reg = render_page(…, dpi_floor=96)`（floor 常量，本地兜底可读下限；不新增 config 键）→ registry 追加 → OCR；
  2. `except RenderError as e:` 分支——`e.kind=="oversize"`（floor 后仍超）→ **诚实 part**：`{"page_number", text:"", routing:[{method:"local-ocr-fallback", note:"render_oversize 先降档重渲(≤dpi_floor=96)仍>10MB"}]}` + `_marker(…, reason="render_oversize")`（**不得落空文本假装 OCR、不得仅标记即过**）；`e.kind=="render_failed"` → marker degraded + 走现局部兜底语义；
  3. OCR/OcrUnavailable 单独 try，仅 OCR 失败才 `local_ocr_unavailable` 标记。
- 断言（mock render/ocr 模块）：`render_page` side_effect=[RenderError oversize, floor-reg]→二次调用断言 dpi_floor 生效 + 最终 png ≤10MB + OCR 产出文本非空（patch ocr_page 返回行级文本）；`render_page` 恒抛 oversize→part routing note 含 render_oversize。
