## 2. 现状缺口（来自遗留清单，逐项为据）

### 2.1 测试守卫缺失（C-1..C-6、C-A2/C-A5、S9-A1/A2、L-验收-2）

- 弹选 TTY 分支无真实交互验证（C-1；**平台钉死**：Windows 无 os.openpty/pty——真实 TTY 端到端 POSIX-only，Windows 用函数级 input() 覆盖 TTY 行为 + 非 TTY 真实子进程，禁空转 skip）
- test_render ⑥ 未断言降档登记且夹具不足（C-2）；schema/method or 放宽（C-3，实物在 **test_orchestrator_pdf.py:97-100/208**，非 test_render）
- test_triage 零页空转跳过、blank_pages 弱断言（C-4）
- ci_all 绿灯不要求 pass>0（C-6）；check_doc_consistency 空转分支+只单向（C-A2）
- MockM4 带默认值不校验转发（S9-A1）；--pages 无单测+无效/越界规格静默空产物（S9-A2）
- TTY 分支测试卫生（C-A5）；缺 _scan_page_glm 级 images mock 守卫（L-验收-2）

### 2.2 产品码行为缺陷/局部（C-5/C-7/C-8/C-A1/C-A3/C-A4、S9-A3）

- render_page target_width 指定时降档循环失效（C-5，当前不可达潜伏）
- maybe_offer_degrade 签名缺 cfg；run_pdf 每扫描页重建 VisionClient（C-7）
- _scan_page_local 吞 RenderError(oversize)→扫描页落空文本（C-8）
- _structural_ok 对 GPU 库"存在即拒绝"易误伤（C-A1）
- _marker 路径双模式不一致（C-A3）；render_reg_for 残留导入（C-A4）
- ctx.page 取值口径不统一（CROP 有兜底 / SECOND 无兜底）（S9-A3）

### 2.3 较大接线（S9-1）

- html_to_grid 不产表 bbox → 同页多缺陷表缓存指纹等价（跨表错误命中窗口）

### 2.4 文档滞后（S9-A4、L-验收-1）

## 3. 目标（In Scope）

1. **测试守卫完备**：C-1..C-6、S9-A1/A2、C-A5、L-验收-2 → 补真实 pty 弹选、降档登记断言、去 or、零页真测、pass>0 守卫、mock 严格化、--pages 单测+无效报错、scan_page_glm 级 images mock。
2. **产品码行为修正**：C-5（target_width 降档循环重构）、C-7（签名对齐+client 一次性）、C-8（oversize 区分处理）、C-A1（GPU 库可配置放行）、C-A3（marker 路径统一）、C-A4（残留导入清理）、S9-A3（ctx.page 统一）。
3. **缓存碰撞消除（S9-1）**：真实表 bbox 接线或防碰撞——**两路线判据与成本显式化**：①真实 bbox 路线=layout_details 表块 bbox 对位（Step 3/4 用既有 GLM 夹具预研对位成功率，可行性决定是否采纳）；②禁命中路线=同页同退化 bbox 的二次 CROP/SECOND 不命中缓存（显式接受重跑逐表出域的成本口径，BudgetGate 联动 Step 5 定）。
4. **文档同步（S9-A4）**：v1.2 修订稿补 process_page_md 新参调用清单；L-验收-1 在文档注明 M13 边界。
5. **回归保持**：既有 114 断言 + 新增断言全绿；真实样件（文字层+扫描）复验。

## 6. 验收指标框架

1. CI 全绿：既有 114 + 新增断言（R-01..R-14 各有可失败断言，无空转 skip），pass>0 守卫生效。
2. 弹选 TTY：TTY 分支行为（选 C/B）函数级真实 input() 覆盖 + "无产物"断言；非 TTY 真实子进程不变；真实 TTY 端到端=POSIX-only 可选测试（Windows 平台边界如实声明）。
3. 缓存（S9-1，判据随路线）：真实 bbox 路线=同页两表 bbox 不同；禁命中路线=同页退化 bbox 第二次 CROP/SECOND 不命中缓存（两次独立出域断言）。
4. 降档：target_width 指定 + 大页夹具 → 正确降档登记（唯一判据，render 补 downsampled_from 视 Step 3 定）。
5. oversize：扫描页渲染超限 → **先降档重渲**（复用 M2 降档）再 OCR；仍超限才诚实标记且原因入页 part（reason=render_oversize）——不得仅标记即过。
6. 文档-实物：**落点二选一（Step 3 定）**——a) 冻结《升级-补全v4入口-详细技术设计.md》§3.2 调用示例加修订注（含 png/doc_sha1/render_reg）；b) 新参调用清单写入《详细技术设计.md》v1.2 §6.12。L-验收-1 的 M13 边界注落点=《需求确定书.md》v2.4 FR-F1 或《详细技术设计.md》v1.2 §6.13 补一句能力边界句（正文不入 md/html，保留 JSON）。
7. 真实样件复验：文字层样件 + 扫描样件（前 N 页）跑通。

## 7. 约束

- 不重开冻结决策；改动锚定冻结/遗留条目编号。
- 编码纪律沿用（UTF-8 BOM 等）；测试全离线可跑（出域项仅样件复验）。
- 每组修复后确定性自检；CI 一键复跑。
