# 升级 DSH 后必须「重新渲染」——标准说法（其他机器通用）

> 适用：任何一台源码树安装的 DSH 机器。核心结论一句话：
> **DSH 升级/改插件后，服务端重启只是第一步；浏览器还停在旧页面 = 旧前端缓存，必须硬刷新（Ctrl+F5）重新加载，界面（如左上角品牌名）才正确。**

---

## 一、一句话版（直接说这句）

「按 dsh-launcher 技能的升级流程执行：进入源码树 git pull → pnpm install → pnpm build → 重跑 setup.ps1（自动按清单重打补丁）→ 重启 dsh web；**最后必须硬刷新浏览器（Ctrl+F5）或重新打开 http://127.0.0.1:3080**，否则浏览器缓存旧前端，左上角品牌名等界面显示旧内容或兜底文字（如 "DSH Local Build"）。刷新后 client 插件按新 rev 重新加载，界面才正确。」

## 二、完整版（贴给 AI agent 的升级指令）

```
【DSH 升级】<当前版本> → <目标版本>
请将本机 DSH 升级到官方最新版。本机为源码树安装（源码树位置：<C:\Users\<用户名>\deepseek-harness>，
启动器安装目录：<如 D:\DSHS>），请按 dsh-launcher 技能的升级流程执行：
1. 进入源码树，git pull 拉取最新源码；
2. 构建：pnpm install 后 pnpm build；
3. 重跑 dsh-launcher 的 setup.ps1（-InstallDir "<启动器目录>" -NoShortcut，自动按清单重打补丁）；
4. 重启 dsh web（并视需要重启托盘，让托盘顶行版本刷新）；
5. 【关键】完成后必须硬刷新浏览器（Ctrl+F5）重新加载 http://127.0.0.1:3080，
   否则浏览器缓存旧前端，界面（左上角品牌名、版本相关显示）会显示旧内容或兜底文字
   （如侧边栏左上角出现 "DSH Local Build"）。
6. 验证：dsh --version 显示目标版本；页面刷新后左上角为官方 "DeepSeek Harness" 字标；
   补丁已生效（~\.dsh\patches-backup\<补丁id> 存在，或跑补丁引擎 -CheckOnly）。
```

## 三、为什么必须「重新渲染」（原理）

DSH 前端是 **client-plugin 图**：index.html 里的 `window.__DSH_BOOT__` 指向一批带
rev 哈希的插件 JS（`/plugins/@deepseek-ai/.../client.js?rev=<hash>`）。

- 升级/重打补丁/新增前端插件后，服务端重新生成的插件图 rev 全部变了；
- 浏览器若还停着旧标签页或命中缓存，就继续跑**旧插件**（旧 brand、旧界面、旧版本显示）；
- 例：0.1.1-rc.2 新增 `dsh-client-ui-brand-official` 插件提供官方字标；浏览器不刷新时
  侧边栏左上角 `sidebar.brand.name` 槽位没有新插件注册，就落到兜底文字 **"DSH Local Build"**；
- 硬刷新（Ctrl+F5）让浏览器按新 rev 重新拉取全部 client 插件 → 界面才正确。

## 四、类似的其他情况（同一招：重启 web + 硬刷新）

| 场景 | 服务端要做的 | 浏览器 |
|---|---|---|
| DSH 版本升级 | git pull + pnpm install + pnpm build + 重跑 setup.ps1 + 重启 web | Ctrl+F5 |
| 补丁重打（setup.ps1 / 重打全部补丁.bat） | 重跑后**重启 web**（补丁 requiresRestart） | Ctrl+F5 |
| 启动器脚本更新（托盘「一键同步启动脚本」，GitHub 同步） | 自动重跑 setup.ps1 + 托盘自重启；web 建议重启 | Ctrl+F5 |
| 前端插件包新增/改名/重构（如 web-react → ui-brand-official） | 重建 build:web + 重启 web | Ctrl+F5 |
| 页面出现兜底文字/旧版本/旧 UI/布局错乱 | 先确认 web 已用新构建重启 | **先硬刷新**，仍不对再查服务端 |

> 判断服务端是否已是新构建：看启动页 `window.__DSH_BOOT__` 的 `rev` 是否有变化，
> 或 `dsh --version` 是否为目标版本。

## 五、验证清单（刷新后）

- [ ] `dsh --version` = 目标版本
- [ ] 浏览器硬刷新后左上角为官方 "DeepSeek Harness" 字标（不是 "DSH Local Build"）
- [ ] 启动页 `__DSH_BOOT__` rev 已变化（新图）
- [ ] 补丁已重打：`~\.dsh\patches-backup\<补丁id>\` 存在，或补丁引擎 `-CheckOnly` 通过
- [ ] 托盘顶行显示 "DSH 版本 <目标版本>"（托盘需在升级后重启过）
